# Temper R4 — continuous flush front

Approved direction: a continuous bent-aluminum front, a flush glass window, three flush
buttons, and a hidden removable electronics carrier. There is no separate exterior panel.

The lens is 108x38x2mm, nominal outer surface Z=0 in the front-face coordinate system.
The aluminum is 2mm; the window is 108.8x38.8 with R4.4 corners, leaving a nominal0.4mm
perimeter joint. A 118x48x1.2mm rear ring supports inward loads through an allocated0.3mm
bondline. Its opening is100x30. Adhesion supplies outward retention; this is not qualified.
A flush-filled perimeter seal is modeled. There is no overlapping front rim.

A separate internal carrier holds the OLED and button PCB. Six bonded stud-pad envelopes
attach it to the sheet without holes through the visible front. Nuts and spacers allow
carrier removal without disturbing the lens bond. Mount strength, creep, locking, material,
fastener supplier and service tool access need prototype validation.

The three button tops are also at Z=0, with nominal0.3mm radial clearance to sheet holes.
One continuous membrane sits behind all three holes. Its perimeter is clamped in a2.5mm
gap between sheet and carrier, modeled from a3.125mm free-height allocation (20%nominal).
This is a rigid installed shape, not a validated elastomer force/stroke/overtravel model.
A0.2mm rest gap to the unselected switch actuators is retained.

## Known limit

The shallow folded front roof clears the rear carrier and lid in nominal saved geometry,
and keeps a closed chamber around the **historical imported PCB**. Its bend, seam,
fastening, insulation, gland and service process are allocations awaiting physical design.
The current 240x160mm full-bridge PCB and its 305mm-class shared sink are different
hardware; their integrated fit and airflow are not established by this assembly.
This revision implements the approved exterior and mounting concept; it is not a
manufacturing, hot-oil, ingress, thermal, electrical or product-safety release.

## Rebuild

Git carries source, the historical PCB input, and compact receipts. The large
STEP/STL/DXF/mesh exports, inherited viewer assets, PDFs and zip stay local.
Rebuild STEP geometry before running checks on a fresh checkout; `catalog.json`
is regenerated by the assembly build. The saved [section image](renders/r4-chamber-section.png)
shows the corrected compartment and can be regenerated with
`python checks/render_chamber_section.py` using the CAD and Matplotlib dependencies.

CadQuery2.6.1 for source and nominal checks; cadgen0.7.9/build123d for independent checks.
Use included requirements files and a writable CADGEN_CACHE_DIR. The snapshot wrapper
resolves the relative job template inside this package after relocation.

    python src/assembly.py
    python checks/front_panel.py
    python checks/service_access.py
    python checks/validate.py
    python checks/dxf.py
    python checks/assembly_correspondence.py
    python checks/export_panel_stl.py
    python checks/snapshots.py
    python package.py

The panel check fails on any modeled front/chamber or front/historical-PCB collision.
STEP is authoritative. Complete assembly correspondence checks named saved geometry against
individual STEP by bounds, volume and solid count, not topology or physical performance.
Original R3 and earlier outputs are preserved. Inherited PDF manufacturing drawings refer
to older knob/sensor/support geometry and MUST NOT be used for this flush-front revision.
No firmware or PCB design changes were made.
