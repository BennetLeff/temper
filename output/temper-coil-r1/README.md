# temper-coil-r1: the induction coil prototype, modelled and made windable at home

**Status (2026-10-18): modelled only.** No coil has been wound or measured. Every number below comes from a committed script in this folder, named next to it. **Measured** appears only where a measurement exists, and none does yet.

The goal is the owner's: **heat a pan on the first native-21 power boards** with a coil wound on the home bench. This study:
- fixes the winding (turns, layout, target L);
- checks it against the power stage and firmware;
- gives the former, the jig, the build and measurement procedure, and the order list.

## 1. Results

### The winding: R1 = 14.47 inner + 6.46 outer = 20.93 turns, ~81 µH free-air

|---|---|---|---|
| L free-air, 40 kHz | 87.7 µH | **81.1 µH** | `run_free_air.py` (2D × 3D bar factor) |
| L installed, no pan | 83.3 µH | **77.0 µH** (0.950 ×) | same |
| R_dc 25 °C (270 × 0.10, incl. 0.4 m of leads and 1 mΩ terminations) | 86.2 mΩ | **83.2 mΩ** | `litz.py` |
| R_ac 40 kHz, 25 °C / 100 °C | 90.0 / 113.8 mΩ | **86.6 / 109.6 mΩ** (F_R 1.04) | `run_free_air.py` |
| R_ac 20/30/40/50/60 kHz, 25 °C | 87.1 / 88.3 / 90.0 / 92.2 / 94.9 mΩ | 84.1 / 85.1 / 86.6 / 88.5 / 90.9 mΩ | same |
| Spec limits | | R_dc ≤ 100 mΩ; R_ac ≤ 193 mΩ at 25 °C, ≤ 250 mΩ at 100 °C: **pass with ≥ 2× margin** | spec rows 4–5 |

**"~20 or ~21.5 turns" resolved:** neither number is right for these bars.
- On R43's radial bands with ten 90 × 15 × 5 bars, **70 µH needs 19.1 turns and 80 µH needs 20.75** (3D-corrected fit `L = 0.174 n_in² + 0.221 n_in·n_out + 0.578 n_out²` µH, rms error in `free_air.json`).
- R43's 21.93 turns give 87.7 µH, 25 % over the 70 µH target.

**What sets L:**
- Free-air L is insensitive to the ferrite's µ: µ 1000 / 2500 / 5000 give 86.9 / 87.7 / 88.0 µH.
- It is sensitive to the bar layout: the 2D homogenised model overstates it by 11 % (next table).

**Tuning:** the R1 former has one spare outer turn of notches.

| State | L free-air |
|---|---|
| R1 + spare turn | 89.9 µH |
| R1 | 81.1 µH |
| −0.5 turn | 76.8 µH |
| −1 turn | 72.5 µH |

One half-turn is ≈ 4.3 µH (`free_air.json`, `trim_heating.json`).

**Build fidelity:** every home-build error tried moves L by ≤ 1.2 % and loaded R by ≤ 1.4 %, less than one tuning step (`fidelity.py`, TABLES.md). The errors tried were:
- bundle 0.3 mm proud;
- roof 0.2 mm thick;
- bars 0.5 mm low or 2 mm out;
- pitch ±3 %;
- random turn-radius error σ 0.6 mm.

### 2D against 3D: where they disagree and which to trust

| Check | 2D axisymmetric (homogenised bars) | 3D 18° sector, discrete bars (Elmer, remote box) | Verdict |
|---|---|---|---|
| Air core, same winding | 58.31 µH | 57.99 µH | agree within 0.55 %: the winding model is right |
| Free air with bars | 96.10 µH | **86.92 µH** (h 1 / 0.7 / 0.5 → 86.49 / 86.69 / 86.80, extrapolated) | **2D is 11 % high.** Smearing 10 bars into an azimuthal sheet overstates the flux return. **Trust 3D**: k_free = 0.909 |
| Over 430 pan (µ 200) | L 56.3, R 5.87 Ω | L 53.1, R 5.16 Ω | 2D L is 5 % high and R 12 % high: k_L = 0.949, k_R = 0.880 (cast iron: 0.950 / 0.892) |
| Transfer test (80 µH layout solved in 3D) | 2D × k: free 79.6, 430 L 48.6, R 4.70 | free 79.3, L 48.4, R 4.65 | the factors carry to other layouts within 0.4 % / 1.1 % |

**Solver validation** (`validate.py`):
- the air-core L matches the filament sum to −0.06 %;
- the ring over a half-space matches Dodd–Deeds within 0.9 % (ΔR) and 0.1 % (ΔX);
- 0.6× mesh refinement moves L by +0.2 % and R by −1.0 %.

**Rule used everywhere:** the 2D model carries the 3D factors to other layouts, pans and frequencies, and the 3D discrete-bar solve is the number trusted.

**What neither model has:**
- the non-axisymmetric heat-sink spreader bar that reaches Z95 under the coil;
- the real lead loops;
- the enclosure's non-round parts. The enclosure is modelled as rings and a disc: base, seat ring, fence ring.

### Pans: installed, pan base on the 4 mm glass at Z110, 40 kHz (`run_pans.py`)

| Pan (Ø240) | assumed µ low / nom / high | Loaded L (µH) | Reflected R (Ω) | Heat: r < 55 / 55–92 / ≥ 92 mm |
|---|---|---|---|---|
| 430 stainless 1 mm | 50 / 200 / 500 | 36.7 / **49.4** / 62.7 | 2.75 / 4.71 / 6.24 | 19 / 52 / 29 % |
| Tri-ply (430 / Al / 304) | same | 37.0 / 49.1 / 62.1 | 2.89 / 4.60 / 6.05 | 20 / 53 / 28 % |
| Cast iron 4.5 mm (the spec's reference class) | 50 / 100 / 300 | 39.6 / **46.1** / 61.0 | 3.27 / 4.26 / 6.12 | 19 / 51 / 30 % |
| Carbon steel 2 mm | 100 / 200 / 500 | 32.9 / 36.9 / 44.4 | 2.09 / 2.83 / 4.03 | 20 / 49 / 31 % |
| Aluminium 3 mm (no heat; detect case) | 1 | 23.6 | 0.13 | — |

- **Pan µ is the biggest unknown** and it is assumed: low/high bracket it. Bench M4 measures it.
- **Spec row 3** (≥ 41.5 µH on the reference cast-iron pan): R1 gives 46.1 µH, passes. A 70 µH coil gives **39.7 µH, which fails.**
- **Large-signal estimate** (Fröhlich µ(H), 430 at 17.5 / 28 A): L 44.0 / 42.0 µH, R 4.18 / 3.94 Ω, 11–16 % below small-signal. The bench LCR reads small-signal; the firmware measures f_res live.
- **Ø180 pans** take 0 % at r ≥ 92: all their heat is inside r 90.
- **Rim heating:** on a Ø240 pan, ~29 % of the heat goes beyond r92 (the outer section's job). Each half-turn trimmed costs ~2 points: 32 / 29 / 27 / 25 % for the spare / R1 / −0.5 / −1 states (`trim_heating.py`).

### System check against native-21 (`system_check.py`)

**Plant:** series RLC, first harmonic, line-cycle averaged, the same plant as `firmware/test/test_tank_freq.c`:
- bank 5 × 100 nF ±5 %;
- V1 = 0.9 × line;
- peak = 2.17 × RMS.

**Loop end point as `tank_freq.h` defines it:** start at 60 kHz and step down while all of these hold:
- f ≥ 1.05 f_res;
- lag ≥ 45°;
- I ≤ ceiling;
- P ≤ 1239 W hold.

**Runs:** 108 runs per basis (pans × µ × 108/120/132 V × C −5/0/+5 %), on two pan bases:
- the **model** (this study's FEM pans);
- the round-4 **priors** (`coil_mc.rs` classes), so the conclusion does not rest on one set of assumptions.

| R1 at the shipping 17.5 A ceiling | Model basis | Priors basis |
|---|---|---|
| Delivered power, min / median | **780 / 1041 W** | 208 / 720 W |
| Full power (≥ 97 % of the 1239 W hold) | 24 % of runs (45 % with a 30° lag rule) | 3 % |
| Binding limit | ceiling 44, **lag 45**, hold 18 runs | ceiling 154, f_min 23, hold 3 of 180 runs |
| f_op / f_res | 35.2–60.0 / 27.3–41.4 kHz; f/f_res ≥ 1.26 | 35.0–48.2 / 26.4–34.6; ≥ 1.21 |
| Tank peak / bank V_C | ≤ 38.3 A; **≤ 143 V rms / 311 V pk** (30° rule) | ≤ 38.0 A; ≤ 165 / 359 V |
| Over the ceiling already at 60 kHz | 1 run (carbon steel, µ low) | 0 |

**Reading the table:**
- On every ferrous pan in the model basis, R1 delivers ≥ 780 W at 17.5 A: **it heats a pan.**
- Power is capped by the 17.5 A ceiling and by the 45° lag rule, not by the coil.

**Comparison with other layouts** (same 17.5 A, 45° rule):

| Layout | Full power (model) | Median P (model) | Over ceiling at 60 kHz | Median P (priors) |
|---|---|---|---|---|
| 70 µH design | 32 % | 1084 W | **14 runs** | 658 W |
| R1 | 24 % | 1041 W | 1 | 720 W |
| R43 as drawn | 20 % | 1075 W | 0 | 714 W |

At a 24 A ceiling the 70 µH coil yields more: 79 % against 63 % full power.

**Special loads at the loop's start** (R1, 120–132 V):
- **No pan:** 4.5–5.1 A at 60 kHz (Q 257, f_res 25–26 kHz). The loop then walks down to 35 kHz and sits there at **13–16 A and 19–28 W**, under the 17.5 A no-pan clamp.
- **Aluminium Ø240:** **28–36 A rms at 60 kHz.** The tank peak estimate (2.17 × RMS) of 62–79 A crosses the firmware peak trip (41 A at 17.5 A) and the stage-15 CT band (64.55–76.09 A). It trips before the loop can act.

### Ferrite (3D bar field; `ferrite.py`)

The figures come from the 80 µH layout solved in 3D. R1 has the same bands and 0.9 % more turns, so its B is about 1 % higher.

| Condition | Peak B in the bars | Fraction of PC95 Bs at 100 °C (410 mT) |
|---|---|---|
| No pan, 17.5 A rms crest (38 A pk) | 189 mT | 0.46 |
| No pan, 28 A rms crest | 303 mT | 0.74 |
| No pan, firmware peak-trip cap 62 A | 309 mT | 0.75 |
| No pan, CT band top 76 A | 380 mT | 0.93 |
| No pan, **spec row 7's 98 A** | 489 mT | **1.19, fails** |
| 430 pan, 98 A | 336 mT | 0.82 |

- Bs is reached at 82 A peak with no pan, 120 A with a pan.
- Core loss: 0.9–2.0 W at 17.5 A and 3.2–6.8 W at 28 A, no pan, 35–60 kHz (Steinmetz anchored at the PC95 datasheet point; an estimate).

### The firmware's 55 µH / 0.5 µF against the spec's 70 µH

They are different quantities, not a conflict:
- **0.5 µF** is the bank.
- **55 µH is a loaded L:** a coil over a pan, the only kind of L the firmware loop ever sees with a load.
- The spec's **70 µH is free-air** (66 installed).

The model's loaded L for R1 spans **33–63 µH** across pan class and µ, so 55 µH sits in the upper middle of that range. The tests' weakness is that they use one L (and R 1.0–3.5 Ω, below most of the model's 2.1–6.2 Ω), not that the value is wrong (recommendation F1).

## 2. Decisions

Each decision gives the reasoning and what would reverse it.

**D1. Trust the 3D discrete-bar solve; carry it with the 2D model; calibrate on the bench.**
- *Why:* the 3D solve resolves the bars; the 2D model's only error is the bar smearing, measured at 11 % and transferable within 0.4 %.
- *Reverses if:* the wound coil's free-air L differs from the model state by more than ~5 %. Then the bars' real µ or dimensions differ: `tune.py` records the ratio, and the model is re-anchored.

**D2. Prototype target ~81 µH free-air (spec alternate B), wound as R1 with one spare outer turn; tune window 76–86 µH; never below 5.46 outer turns.**
- *Why:*
  1. It passes row 3 on the reference cast-iron pan (46.1 against 41.5 µH), where 70 µH fails (39.7).
  2. It runs over the ceiling at 60 kHz in 1 run against 14 for 70 µH (carbon steel, and 430 / tri-ply at low µ), where the loop has no frequency left to retreat to.
  3. It gives similar power at 17.5 A (median 1041 against 1084 W model; 720 against 658 W priors).
  4. It keeps R43's radial bands, start/end angles, lead routes, NTC pad and lugs. Only the inner comb pitch changes, 3.568 → 3.815 mm.
- The 5.46-turn floor holds because at 4.96 outer turns the cast-iron loaded L drops to 39.8 µH, under the floor.
- *Reverses if:*
  - the commissioned ceiling rises to ≥ 24 A: then trim one turn (72.5 µH), and consider ~70 µH for the next former;
  - bench pans come out lag-limited with high R: lower L gives more power there.

**D3. Keep the 0.5 µF bank (5 × B32643H8104J000); no board change for the coil.**
- *Why:* f_res 27–41 kHz keeps the operating point inside 35–60 kHz with f/f_res ≥ 1.21.
- *Margins:*
  - V_C ≤ 143 V rms / 311 V pk at 17.5 A (priors: 165 / 359; priors at 28 A: 266 / 577 V pk), against 700 Vac / 2000 Vdc;
  - capacitor current 3.5 A each at 17.5 A, against the part's 24 A.
- *Reverses if:* the ceiling goes to 28 A with low-R pans and the 85 °C capacitor curve, which is the power stage's existing check.

**D4. First coils in stock solderable Litz; the class-200 270 × 0.10 is for the qualification coil.**
- *Why:* grade-200 enamel won't solder-strip at home, and the custom wire is a ~6-week, £1000-MOQ item. Stock 1000 × 0.05 (RMC) or 1050 × 0.05 (Elecify) passes rows 4–5 in the model: 90 / 86 mΩ R_dc. Elecify 200 × 0.10 fails row 4.
- *Cost:* the class is unstated (treat as 155). **Winding ≤ 130 °C** in first-power tests.
- *Reverses if:* a stock datasheet shows class 200, or the custom wire is in hand.

**D5. A cheap former is electrically good enough.**
- *Why:* all modelled home-build errors are ≤ 1.2 % in L, below the 5 % tuning step.
- *Reverses if:* M2 shows L scatter between coils above ~3 % that tuning cannot explain.

**D6. Former route.**
- **Coil 1:** a printed former (route B, five 72° segments that fit a 180 mm bed, PC/PA-CF/ASA). With no printer, the FR4-sheet route C (1 mm FR4 roof, 1:1 template, pencil ticks plus spacer cord).
- **In parallel:** order the G11 CNC former (route A) for the coil that goes on the board for sustained heating.
- *Fidelity cost of B/C:*
  - L ≤ 1.2 %;
  - temperature: PLA and PETG are excluded; ASA is ~100 °C class and PC ~140 °C class (typical, not checked);
  - outer comb teeth 0.46–0.61 mm in print;
  - route C has no comb and no NTC pad.
- `former.py` rebuilds R43's former exactly: the boolean difference against the frozen R43 STEP is 0 mm³ (`cad/check_former.py`).
- *Reverses if:* M2 or first power shows the printed former deforming (bonding lost, turns lifting), in which case go straight to A.

**D7. Jig: a wooden turntable, no 3D printer assumed.** Every part is plywood or dowel, and the one printable part (the centring boss) has a plywood version.
- No metal is above the top plate, which is 149 mm below the winding, and the coil sits ~420 mm above the bench. **L can be measured on the jig**, so tuning needs no unmounting.
- Tension comes from a felt brake on the spool, never on the wire, read with a luggage scale.
- Turns are counted with a tally counter plus 10° ticks.
- *Reverses if:* M2 on the jig and off the jig (coil on a cardboard box) differ by > 0.5 %.

**D8. Measurement: an LCR meter for L (TH2830 class, 20–60 kHz) and a ring-down for R_ac.** At Q ≈ 230 an LCR's R reading carries roughly ±20 mΩ, so R_ac is confirmed from the ring-down decay.

**D9. Ferrite: R43's ten 90 × 15 × 5 PC95 bars are adequate at the shipping ceiling** (0.46 Bs at crest with no pan).
- *Reverses if:* the ceiling goes to 28 A and the coil runs with no pan (0.74 Bs). Production should also answer row 7 (next section).

## 3. Recommendations to the power stage and firmware

These are recommendations only; nothing on the board or in the firmware was edited.

**F1. Widen the test plants in `firmware/test/test_tank_freq.c`.** All cases use L = 55 µH (one uses 60).
- Add the model's corners for R1 at 40 kHz:
  - 33 µH / 2.1 Ω (carbon steel, µ low);
  - 46 µH / 4.3 Ω (cast iron, nominal);
  - 63 µH / 6.2 Ω (430, µ high).
- Add the special loads:
  - no pan, 77 µH / 0.13 Ω, Q ≈ 250;
  - aluminium, 23.6 µH / 0.24 Ω.
- Keep a low-R case near 1 Ω for the priors basis.
- In `tank_freq.h`, update the comment "f_res ≤ 28.4 kHz at 70 uH / 0.45 uF" to the coil of record: 77 µH installed, 0.475–0.525 µF, f_res 25.0–26.3 kHz. The conclusion is unchanged.

**F2. Make the ZVS lag threshold Q-aware.**
- **Today:** `zvs_lag_deg` is fixed at 45°, and `tank_freq_config_ok()` rejects anything below 45°. The 45° proof covers Q ≤ 10, but loaded Q here is 2–4. That forces f ≥ ~1.2 f_res and makes **lag the binding limit in 45 of 108 model-basis runs.**
- **Proposal:** lag_min = max(floor, atan(Q_fit·(1.05 − 1/1.05)) + margin), using the existing two-point fit's L/R. Keep 45° whenever there is no valid fit.
- **Effect:** with 30° the full-power share goes from 24 % to 45 %, and V_C stays ≤ 311 V pk.
- **Owner check:** the power stage must confirm the commutation current I_pk·sin(lag) at 30° against the dead-time charge.

**F3. Add a pan-detect probe before full drive.**
- An aluminium Ø240 pan draws 28–36 A rms at the 60 kHz start, which trips the firmware peak trip and probably the CT band.
- The probe can be a few cycles, or reduced duty, at f_max. Measure I and lag, then classify:
  - **refuse** if Q > 10 with R < 0.8 Ω (aluminium or no pan);
  - **run** if Q ≤ 10.

**F4. Stop on no-pan instead of clamping.**
- With no pan the loop settles at 35 kHz, drawing 13–16 A and 19–28 W indefinitely under the 17.5 A clamp.
- After `pan_confirm_halves` without evidence (Q > `pan_q_max`):
  - stop the bridge;
  - report no-pan;
  - re-probe periodically.

**Spec** (`docs/hardware/TANK_COIL_SPECIFICATION.md`). The version read is the main checkout's uncommitted working tree, sha256 637a7603…, read 2026-10-18; this branch's committed copy now carries the coil corrections (dd8e7962d, 93b9ea185); the uncommitted main-checkout copy may differ.

**S1, row 1.** Alternate B is "about 21 turns" in the spec. It is **20.75 turns** on R43's bands with these bars; 70 µH is 19.1. R43's drawn 21.93 turns give 87.7 µH.

**S2, row 7.** 98 A without saturation cannot be met by ten 15 mm bars: 1.19 Bs with no pan.
- *Options:*
  - restate the row at the firmware peak-trip cap of 62 A, where the bars sit at exactly 0.75 Bs with no pan;
  - restate it at the CT band top, 76 A (0.93 Bs with no pan, 0.64 with a pan);
  - or add ferrite for production (row 12 already asks for ≥ 20 mm bars).

**S3, rows 3 and 3b.** These hold for R1 in the model (cast iron 46.1 µH, ratio 0.57). The spec's expected 48 µH for alternate B agrees within 4 %. The ratio window and floor should be re-derived from M4 measurements once real pans are measured.

**S4, rows 8 and 11.** The stock Litz is a documented prototype deviation (D4).

## 4. Open risks

1. **Pan µ** is assumed (µ 50–500 by class). It moves loaded L by ±30 % and R by ±40 %. M4 measures it.
2. **The aluminium start trip** and **the no-pan idle** (F3, F4): firmware behaviour, not coil faults, but the first bench session will meet them.
3. **The 45° lag rule** caps power on low-Q pans (F2).
4. **Row 7 / ferrite at 76–98 A** with no pan (S2).
5. **Unverified ferrite bars.** The eBay listing was unreadable. Measure every bar (M1); the Mouser PC95 plate is the traceable backup.
6. **Class-155 stock Litz** near a 230–250 °C glass underside: limit the winding to 130 °C and watch the thermocouples.
7. **Not modelled:**
   - the heat-sink spreader bar reaching Z95 under the coil (non-axisymmetric; could lower L and add loss);
   - real lead loops;
   - non-round enclosure parts;
   - large-signal pan behaviour beyond the Fröhlich estimate;
   - temperature dependence of pan µ and σ.
8. **The printed former's temperature** and comb-tooth strength (D6).
9. **The termination process** is unqualified until W9's scrap test passes.

## 5. What the owner does next

1. **Order** (ORDER-LIST.md):
   - **Litz:** ask RM Cybernetics for the 1000 × 0.05 price, stock and temperature class, or ask Elecify for the 1050/44 OD and class.
   - **Ferrite:** ask the eBay seller for the PC95 datasheet, or order 5 Mouser PC95 plates.
   - **Termination kit:** solder pot, M4 1.5–2.5 mm² ring terminals and crimper.
   - **LCR meter**, if the bench has none that covers 20–60 kHz.
2. **Build the jig** from `cad/out/jig_dxf/` (one weekend; renders in `renders/jig_assembly.png`).
3. **When the Litz arrives:**
   - measure its OD;
   - run `.venv/bin/python cad/former.py --bundle <OD>`;
   - print the five segments (or cut the FR4 roof and print the template at 100 %);
   - send `former_R1_cnc.step` out for G11 machining in parallel.
4. **Measure the bars** (M1), bond them, and wind coil 1 with the spare turn (BUILD-AND-MEASURE §1).
5. **Tune:** measure free-air L at 40 kHz, run `model/tune.py --L <µH> --outer 7.46`, unwind as it says, re-measure, then bond.
6. **Run M2–M5 and record the traveller.** The M2 and M4 numbers (free-air, plus your pans) are what turn this study's modelled numbers into measured ones. Send them back for a model re-anchor.
7. **Hand F1–F4 and S1–S4 to the power-stage owner.** First power follows BUILD-AND-MEASURE §5: 17.5 A, winding ≤ 130 °C, no aluminium pans until F3.

## 6. Reproduce

Local runs: Python 3.12 venv in this folder (`uv venv .venv && uv pip install numpy scipy build123d pyvista ezdxf shapely meshio gmsh matplotlib`). Run times are on 8 cores.

```

.venv/bin/python model/compare_3d.py        # 3D/2D factors (reads fem3d/results/*.json) -> results/compare_3d.json
.venv/bin/python model/run_free_air.py      # ~3 min  L, R_ac, trims, layouts -> results/free_air.json
.venv/bin/python model/run_pans.py          # ~5 min  pans, heating, large-signal -> results/pans.json
.venv/bin/python model/ferrite.py           # bar B, core loss                -> results/ferrite.json
.venv/bin/python model/system_check.py      # firmware-loop end points        -> results/system.json
.venv/bin/python model/fidelity.py          # ~30 s build-error sensitivity   -> results/fidelity.json
.venv/bin/python model/trim_heating.py      # ~30 s trim states               -> results/trim_heating.json
.venv/bin/python model/report.py            # TABLES.md + summary.json (every number cited here)
.venv/bin/python cad/former.py [--bundle OD] && .venv/bin/python cad/template.py && .venv/bin/python cad/jig.py
.venv/bin/python cad/check_former.py && .venv/bin/python cad/render.py
```

**The 3D runs** (`model/fem3d/run3d.py CASE`) need the remote Elmer box (`bennet@100.121.239.87`, conda env `temper-fem`).
- Each case is < 4 GB and runs in minutes on 4 MPI ranks.
- Results are committed in `model/fem3d/results/`. Field files were deleted on the box and locally after post-processing, so `--post-only` needs a re-run first.
- Cases:
  - free_h1 / h0.7 / h0.5 and air_h0.7: free air and the air-core control;

**Model provenance:** the axisymmetric solver derives from enclosure study 06 `fem_axi.py` (sha256 f2d21553…). It adds discrete stranded turns, anisotropic and nonlinear µ, and cell-centred B. Geometry is R43's (`output/temper-manufacturing-r43/src/r34_world.py`, R37/R40 changes; read-only).
