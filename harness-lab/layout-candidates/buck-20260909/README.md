`candidate.kicad_pcb` is the verified v4 regrouping of the protected
`buck-dev-a` fixture. Open it directly in KiCad. `compact_candidate.py`
reproduces the placement and routing from `candidate-passing-v1.kicad_pcb`
through KiCad 10.0.4's native API. It resets to that checkpoint on each run;
new track UUIDs mean regenerated bytes need fresh measurements.

The controller sits between the input capacitor above it and the bootstrap
capacitor below it. The feedback divider is on its quiet left side. The
inductor and three output capacitors form a power path to the right. All
nine functional components were placed explicitly; the three terminal
proxies, 50 × 40 mm outline, footprint pad geometry, nets, and rules retain
their frozen identities. No production PCB was edited.

## Physical coverage limitation

L2's copied footprint explicitly says **"Stub for Bourns SRP1265A
inductor."** It has two pads, no courtyard, and no 3D body. The native render
therefore shows bare pads, not an inductor envelope. DRC cannot detect body
collisions for this footprint, and the footprint's land pattern is not
manufacturing-qualified.

The Bourns drawing specifies a 13.5 ±0.5 by 12.5 ±0.3 mm body. V4 reserves
the maximum 14.0 × 12.8 mm rectangle around L2, shown on `User.Drawings`;
other components sit outside it. This is a mechanical review aid, not a new
DRC rule or exact 3D model. The terminal footprints are also fixture proxies.
An actual board needs a verified land pattern, courtyard, connectors, and
appropriate copper/thermal design before fabrication. The copied frozen
project continues to ignore `missing_courtyard`; no rule was relaxed here.

The circuit-identity and local layout checks pass. Component derating, model qualification,
16 unresolved mandatory requirements, and powered hardware evidence remain
separate gates. `engineering-evidence/report.json` correctly reports the
complete reference as ineligible.
