# Retained native bridge adapters

This directory retains the native bridge adapters used by the Zapote unit tools:
`block_source.py`, `block_native.py`, and `buck_native.py`.
`circuit_export.py` is their required Atopile resolved-attribute export helper.
These files are restored unchanged from `archive/zapote-coil-intake-2026-09-25`.
The rest of the historical harness lab remains at that archive tag.
