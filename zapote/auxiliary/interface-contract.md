# Auxiliary interface contract — draft U1

Source snapshot and moving Rev38 revision are recorded in [rail-ledger.md](rail-ledger.md). This contract records producer and consumer obligations; it does not select a circuit. U1 proposes separate HOT and SELV acceptance boundaries, pending owner scope confirmation; inverter low-side bias requires its own isolated-output proof.

| Port | Producer obligation | Consumer/failure obligation |
| --- | --- | --- |
| Rev38 raw auxiliary AC input | Fed after reviewed F1/CMC but before the main NTC/bypass, or by an equally early source; exact module input pins and a separate AUX branch fuse/conductor/inrush path required. | Prove rails rise with bypass relay open and PFC RUN low. The nominated off-board Class CC F1 alone does not qualify the smaller AUX branch. Source loss, brownout and hiccup must leave restart disarmed. |
| `AUX15_SOURCE` then `AUX_PROTECTED`, referenced to `HOT0` | Bind the raw producer output, return bond and output cutoff with no bypass feed; bound 14.25–15.75 V normal at the UCC27624, UCC28180 and relay terminals, and fault output peak at UCC27624 VDD. Include source/FET/shunt/wire drop, pulse/startup current and local temperature. | Rev38 supervisors, fast-dip/OV detector, retained trip and gate-disable behavior must be checked against that bound, including HOT logic5 absent. An AC/DC module's OVP *trigger* is not an output-peak guarantee. |
| `HOT_LOGIC5` referenced to `HOT0` | Produce downstream of protected AUX; bound buck startup, efficiency and output capacitor charge as well as HOT receiver, isolation side, watchdog and fault-detector load. | TPS3890 and TLV3202 are powered from this rail, so their outputs alone cannot establish a safe state before it is valid. Its absence must not let the AUX-powered driver enable through a floating control. |
| SELV `+15V` and `+3V3` referenced to SELV `GND` | Select a source input that exists before authorization, plus an explicit HOT/SELV insulation and PE policy, concurrent startup and load envelope. The historical half-bus IRM-10-15 source is not a new Rev38 solution. | Interlock J2 requires 3.135–3.465 V; `SENSOR_LIVE` and AUX fault need real producers. MCU/interlock outputs must inhibit until rail and sense validity, then require a fresh reset edge. |
| Inverter `+15V_LS` referenced to `HV_RETURN`; J5 3V3 referenced to `CTRL_GND` | Provide a separately reviewed isolated gate rail or prove a compliant shared source; define if/how primary `CTRL_GND` joins SELV GND. | Gate-drive unit requires both J2 and J5; low-side pulse/bootstrap startup and loaded timing remain physically unqualified. |
| Cooling fan rail and return | Choose one fan assembly and a source/regulator with start, stall, steady, cable and local-temperature envelopes. | Fan tach alone cannot establish airflow; create an explicit interlock health producer, including power-loss default. |

The authoritative Rev38 restart implementation remains in the PFC unit. This auxiliary unit supplies fault and rail-health conditions and must not independently issue a new ARM/PERMIT event. The rail ownership split is a working proposal; U2 source/protection selection remains blocked on exact voltage/current/time bounds. The frozen active Rev38 proposal is bound by saved-file hashes in [candidate-comparison.md](evidence/candidate-comparison.md). It compares direct IRM-20-15 and regulated IRM-20-24 → LMR36015 HOT paths ahead of LTC4368-2 with external FETs/shunt and TPS54202; it explicitly says no source module is joined. The direct path's conditional static screen leaves as little as 62.5 mV to the protected lower limit at an assumed 50 °C local module temperature, before cutoff and wiring drops. The regulated path has more feedback-only static margin but additional startup and fault modes. Neither is a producer selection. Rev38's `AUX-OVP-WINDOW.md` also rules out the former ±1% TPS26601 divider for the stated 15.75/18.0 V screen; its LTC4368 screen does not establish output peak or startup.
