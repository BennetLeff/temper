# RTD circuit evidence

The current bounded engineering contract is `rtd_contract.json`. Executable
observations are generated by `rtd_observed_faults.py` from the retained static,
transient, short-circuit, and rail-monitor results. `rtd_observed_faults.json`
contains model outputs; it is separate from the unit validator's required
fault verdicts. The passive models are authored from datasheet bounds and are
not vendor transistor models or bench measurements.

The actual implemented circuit is `elec/src/rtd_unit.ato:RTDUnit`, compiled in
`../unit/evidence/source-04/` and bound to the candidate source manifest.
`../unit/candidate/` contains the actual native board, schematic and qualified
libraries. In particular, use the candidate TPS389001 and Samtec footprints;
the `.patch`, proposal `.ato`, and `.kicad_mod` files in this circuit directory
are retained design-history inputs and must not be reapplied as current CAD.

The former SINC/filter timing study is retained historical conditional evidence.
The implemented conductor-fault path uses the actual RTDIN comparator network;
it does not claim vendor-guaranteed MAX31865 SINC behavior. Upstream power loss
has no guaranteed powered-high unit fault output and requires host inhibition.

Physical probe wiring, accuracy, EMC, rail-ramp, and shutdown tests are **NOT RUN**.
See the standalone `../unit/HANDOFF.md` and `../unit/BENCH-OUTLINE.md` for the
interface and future verification boundary.
