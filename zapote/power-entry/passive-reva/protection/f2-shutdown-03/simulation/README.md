# F2 shutdown transient experiment

The canonical host run supersedes `worker-attempt/summary.csv`. It contains
19 scenarios, including four extra PWM phases, an overlapping-pulse timestep
refinement and a separate doubled-charge case. See the parent report for the
final table and `../review-resolution.md` for changes after the frozen review.

This directory contains the executable ngspice model and Rust-only extraction
for the F2-open experiment. Run it from the repository root with:

```sh
zapote/power-entry/passive-reva/protection/f2-shutdown-03/simulation/run_cases.sh
```

The runner uses `/opt/homebrew/bin/ngspice` 45.2, writes each substituted
netlist and log under `raw/`, writes complete `wrdata` traces under `traces/`,
then compiles and runs `extract.rs`. The extractor rejects malformed width,
non-finite values, and non-monotone timestamps. Its endpoint is the first
post-threshold point after the last switch-current pulse where Q, EN and VGS
are all low; an ordinary PWM off-phase is not counted. `i(lboost)` remains a
separate inductor trace. Switch current is measured through the 1 mOhm sense
element (`sw_mid`–`sw_sense`), so the very large impulse values in the
fresh-rearm/reverse stress rows are a behavioral-switch artifact, not a MOSFET
current bound.

The provisional screen is 2 us from the unfiltered divider threshold and
500 V at VD. The three F2-opening rows use L=100/180/216 uH and initial
40/45/50 A conditions; the measured current at the 120 us fuse opening and at
the threshold is retained in `summary.csv`. The 50 A row is repeated at 1 ns
instead of 2 ns to check timestep sensitivity. `slowed_gate_negative` changes
EN propagation to 5 us and intentionally fails the 2 us screen. The retained
XSPICE d_dff supplies a real ARM edge and asynchronous clear, so held ARM does
not invent a restart. `fresh_rearm` records a later pulse after the explicit
post-recovery ARM2 edge, but its behavioral switch impulse is not a physical
qualification result.

`permit_loss_return` and `rails_invalid_return` are supplied qualification
signal tests only: each input is driven low at 80 us and high at 100 us, and
the extraction checks Q, EN and measured switch current remain low afterward.
It also requires switching beforehand, the actual low interval and recovered
inputs. The other qualification input remains valid throughout each test.
They do not model logic5/aux brownout, input clamps, POR, or analog back-power.
`absolute_vd_ov` is deliberately reported failed/indeterminate because the
closed F2 equalizes the initial 430 V diode-side stimulus before the filtered
fault can remain asserted; this is an ineffective-startup stimulus, not a
successful detector claim. `absolute_vb_ov` and the under-absolute reverse
mismatch are retained separately.
All three startup-voltage cases are INDETERMINATE for running-fault timing;
no0µs startup result is accepted as a shutdown latency. Each filter capacitor
is initialized from its own bus in the canonical template.

The circuit is a bounded behavioral plant: Vin=132 Vac crest, healthy diode,
19.8 uF local capacitor, 2.24 mF bank capacitor initially at 410 V, and a
15 V push-pull gate source into 10 ohm + 12 nF + 10 kOhm. Comparator response,
two HCS21 health stages, HCS74 clear, and EN response are explicit timing
surrogates; they are not a vendor end-to-end maximum. No STW65N65DM2AG model,
fuse arc, wiring inductance, nonlinear L(I,T), temperature, parasitic ringing,
or auxiliary supply is claimed. The official UCC27624 vendor-load fixture is
retained and audited by the parent integration work; this model remains the
transparent primary plant experiment.

The final `summary.csv` contains raw measured values and intentional
`FAIL`/`INDETERMINATE` outcomes; they are not tuned to make a protection claim.

Large `.raw` and `.tsv` files are retained losslessly as `.gz`. Decompress them
with `gunzip raw/*.raw.gz traces/*.tsv.gz` before replaying the extractor or
`ngspice -b plot.cir`, or rerun the runner in an isolated copy. The SVG plots
were generated by ngspice; browser visual inspection was unavailable under
the local-file URL policy. Numeric results are from full traces. Four Rust
extractor tests pass; run with `rustc --edition=2021 --test extract.rs -o
/tmp/f2-extract-tests && /tmp/f2-extract-tests` from this directory.
