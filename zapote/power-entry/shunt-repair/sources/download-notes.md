# Manufacturer evidence retrieval

The manufacturer HCSM endpoint rejected direct download in this environment.
The retained Stackpole PDF is a manufacturer-authored 2019 family datasheet
from a distributor mirror. The newer June 2024 family table was also inspected
through the Mouser web result; its HCSM2818 dimensions and conditional 5 W
rating agree. The archived file is explicitly identified as the older revision.

`stackpole-europe-response.html` is a failed HTML retrieval, not a datasheet and
not evidence supporting any rating. Exact source URLs and SHA-256 digests for
the usable PDFs are in `manifest.json`. Availability was checked, not reserved.
