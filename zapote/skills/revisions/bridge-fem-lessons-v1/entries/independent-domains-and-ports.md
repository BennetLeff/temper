# Verify physical domains before trusting solver balance

Require independently checked material volumes, conforming interfaces and true exterior ports. A converged solve can describe the wrong geometry. Compare imposed current times measured potential to Joule heating; compare Joule heat independently to summed boundary reactions. Do not use one calculated quantity as both sides of its own oracle.

Allocate a shared package loss once. Require per-contact and global balance. Keep uncertain package paths, lead material, solder and cooling assumptions separate from numerical validity. A package network node is not a resolved die junction.

Bind exact native trace UUIDs and nets; graph split ordinals can change after width edits. Replay the raw mesh/log/scalar evidence, regenerate physics, and bind the complete evidence directory in the common run receipt. Refreshing producer hashes must not hide changed physics.

This note transfers a validation procedure, never a temperature or current rating. See docs/solutions/best-practices/fem-balance-needs-independent-domains-and-ports.md and its regression links.
