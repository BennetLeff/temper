# Keep electrical and evidence identities independent

Before accepting a replacement divider, calculate its maximum input and tolerance/temperature corners independently; nominal arithmetic from an agent proposal is not enough. Keep physical receiver applicability separate from ideal circuit bounds.

A package name is not an electrical symbol/model identity. Devices sharing a footprint can have different pin meanings. Check datasheet pin names and the rendered symbol as well as the complete pin-number net map.

Compare native exports with saved board bytes and original library semantics. Keep rejecting controls for rehashed contradictions; a matching hash only binds bytes. Do not recreate the oracle from the edited candidate. Use the existing Rust checks and KiCad native placement/extraction rather than writing another geometry convention.

This is a portable procedure. It transfers no voltage, component, spacing, or acceptance value from the voltage unit into another unit. Device applicability and physical tests stay unresolved until supported by evidence.
