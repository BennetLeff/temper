# Native-09 verification, 2026-09-26: designed to JLCPCB

The active board now includes the [label/model presentation revision](presentation/README.md).
Its current hash and fresh checks are recorded there. The reports below remain
the original electrical verification of the pre-presentation board.

Board SHA-256: `ccaa385921f686d6d08859cf4e81fb2e93014c434a935996a85257a1f3594112`.

Native-09 is native-07's routing, replayed onto **native-08**. Native-08 is the
same placement (no part moved; placement metrics identical to native-05),
regenerated with JLCPCB's stackup and one footprint override. The owner chose
JLCPCB on 2026-09-26. This is not a fabrication or powered-operation release.

## Power screen at JLCPCB copper

The screens are the same as for native-07, except that inner layers now use
**61 µm** finished copper, where native-07 assumed 70 µm on every layer.
Nominal IPC-2221B at a 20 °C rise. These are width screens, not ratings.

| Path | native-07 (70 µm assumed) | native-09 (61 µm inner) |
| --- | --- | --- |
| In2 BUS_P local row, 19 A assumed | worst demand/screen 0.805 | **0.886** (12.13 A in 10.87 mm at x 130.25) |
| Western BUS_P neck, In2 + B.Cu, 15 A | 0.443 | **0.457** |
| Western neck, In2 alone (for reference) | 15.88 A screen | 14.41 A screen: below 15 A without the B.Cu parallel |
| SW_B B.Cu tank strip (outer, 70 µm) | 8.4995 mm | 8.474 mm, 25.25 A screen |

The 2 oz inner copper is thinner once finished, which takes back part of the
margin gained in native-07. The B.Cu parallel added for D4 condition 1 is now
necessary: the western In2 section alone would screen below 15 A.

## Limits

The stackup thicknesses come from JLCPCB's stackup API as captured by
github.com/gsuberland/jlcpcb_autogenerated_stackups (normalised_json,
2025-05). Re-check them against the live order form. JLCPCB lists Nan Ya, KB and
Shengyi as laminate suppliers, so the CTI must be confirmed on the order (see
FAB-JLCPCB.md). Via plating is JLCPCB's stated **average** of 18 µm, not a
minimum. Every native-06 open item still applies.
