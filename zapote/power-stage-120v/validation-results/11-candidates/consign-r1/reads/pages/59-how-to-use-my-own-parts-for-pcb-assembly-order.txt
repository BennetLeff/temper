 How to use my own parts for PCB assembly order
 Last updated on Sep 09, 2026
Components purchased through the Pre-Order, Global Sourcing, and Consign Part channels will be stored in the “My Parts Lib”.
If customers would like to use their own parts for assembly orders, component information is required to be listed in the BOM and CPL files. When it comes to the parts selecting page, please pay attention to checking if the components from "My Parts" have been selected. Only parts selected can be assembled on the boards.
How to use parts from Pre-order
1. If there are enough pieces in "My Parts" for the assembly order, the system will use "My Parts" by default.
2. If there are no enough pieces in "My Parts" for the assembly order, the system will use inventory in JLC parts library as the supplement. If the public inventory is not sufficient, we suggest customers placing a pre-order for the parts first to replenish their own inventory, or searching if there are alternatives in JLC parts library to support the assembly order.
How to use parts from Global sourcing/Consignment
1. Before placing an assembly order, customers can confirm whether the parts order has been completed and the specific quantity in My Part Lib.
2. If there are enough pieces in "My Parts" for the assembly order, the system will use "My Parts" by default. If the system does not recognize the exact part, customers can manually search and match with MFR. Part number or JLCPCB Part number.
3. If there are no enough pieces in "My Parts" for the assembly order, "My Parts“ will not be used. The system will use inventory in JLC parts library if the public inventory is sufficient. If the public inventory is insufficient either, we suggest customers replenishing their own inventory first, or searching if there are alternatives in JLC parts library to support the assembly order.
4. Parts from Global sourcing and Consignment could be combined. During matching, the Consignment inventory will be matched first. When the Consignment inventory is insufficient, the Global sourcing inventory will be used in combination.
Notes: 
1. For the same component, inventory from the JLCPCB public stock and Pre-Order parts can be used together. Global Sourcing and Consignment inventory can be used together. Other ways of inventory combination are not supported. 
2. We cannot predict in advance which specific SMT orders the components already received or to be received in your private library will be used for. Before placing an SMT order, if you prepare the parts in advance, you need to check whether the parts are already in your parts lib. Only the parts selected during the component matching stage when placing an SMT order represent those used in this SMT order.
3. If you have no intention of assembling at JLCPCB, ordering parts is not recommended. All parts ordered at JLCPCB are only used for assembly service. If you insist on picking up or require JLC arrange the shipment for the components, the inventory cost and pickup service fee and shipping freight will be charged. Please check the details here.
