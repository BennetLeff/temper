# C1 reference map handback for C2

**Phase:** reference-inductance model only. The board-coupled D1 rerun is pending. The threshold map must not be promoted to a native-15 switching or loss verdict until the D1 matrix is run for both legs.

## Files and keys

- `zvs_thresholds_c1.json`: `thresholds[]` has one row per (`rdt_kohm`, `timing_corner`, `bus_v`, `direction`, `reference_l_scale`). Direction 0 is LS-off/HS-on with **+IL**; direction 1 is HS-off/LS-on with **−IL**. `minimum_bracket_a` is `[last observed fail, first observed pass]`, half-width ≤0.25 A. `crossing_intervals` retains every sampled pass/fail change. `sampled_observations` retains the current grid and refinement outcomes. `no_pass_through_100a`, `at_or_below_0p5a`, and `nonmonotonic_sampled` are deliberately not assigned a scalar threshold.
- `physical_thresholds_10v.json`: supplemental 10 V **signed** die-VDS commutation threshold, refined to ±0.25 A. The strict absolute-5% result remains in `zvs_thresholds_c1.json`. This supplemental criterion accepts a negative diode-clamped incoming VDS when all positive residual die VDS is discharged to ≤5% VBUS throughout the 20 ns precommand interval. Continuous forward body-diode current is reported separately per sampled current. It is not a native-15 hardware guarantee.
- `sensitivity.csv`: threshold comparison for 39/51 kΩ typical timing at reference L ×0.5/×1/×3. Package inductance in the Infineon model is internal and unscaled.
- `outputs/waveform_metrics.csv`: one row per successfully simulated current/bus/direction/dead-time/L/step case, including threshold-search grid and bisects. Use `waveform` to locate the ignored raw `commutation.csv.gz` and adjacent `case.json`/`ngspice.log.gz` under `outputs/runs/` in this worktree. `run_c1.py` reproduces them from committed inputs and the separately fetched, pinned vendor model.

## Time and current definitions

Driver dead time is the **output-command 7.5 V crossing gap** from the A1 approximation. `command_off_s`/`command_on_s` are its actual simulated crossings. The ZVS flag uses incoming **die** |VDS| ≤5% of that case's bus voltage for the full 20 ns before `command_on_s`. It is a diagnostic, not a measured diode-conduction condition. `edge_end_s` is switch-node 90%/10% transition completion. `incoming_die_vds_pre20_min_v`/`max_v` preserve voltage polarity; `positive_residual_5pct_pass` and `forward_diode_clamped_pre20` identify completed discharge/continuous diode clamp even when a ~1 V negative diode drop fails the 10 V strict absolute-5% test. `stable_incoming_die_vds_5pct_start_s` is the final entrance into the 5% die-VDS band that remains there to the command; this can differ from `edge_end_s` when the node rings.

The vendor L1 model's `-i(V_sense2)` is positive for **incoming body-diode forward current**. `diode_forward_charge_before_command_c` and `diode_dwell_above_0p1a_ns` use only the outgoing-command to incoming-command window. `incoming_channel_current_onset_s` is the first post-command time where |Ichannel| is at least `max(0.1 A, 0.1×|IL|)` for two nanoseconds **and** die VGS≥3.5 V, Infineon CFD7 Table 4 printed p.5 minimum VGS(th) at only 2.91 mA. This remains an analysis surrogate, not a physical switching guarantee, because the vendor `V_Ichannel` probe includes a breakdown term. `diode_dwell_until_channel_ns` and `diode_forward_charge_until_channel_c` include the post-command interval up to that onset. `avalanche_or_overstress` marks either modeled die-VDS peak≥650 V; `peak_die_vds_any_v` gives the peak. Such cases have `incoming_channel_onset_invalid_due_overstress=true`, a null qualified onset, and null diode-charge-to-channel fields; exclude them from C2 normal interpolation. `incoming_channel_onset_right_censored` separately warns when the waveform ends before a gate-qualified current onset. `diode_forward_charge_full_saved_window_c` and `diode_reverse_charge_after_channel_c` retain additional model branch diagnostics through the saved command+250 ns tail; this finite window is not a datasheet Qrr specification. `external_reverse_charge_before_command_c` comes from the **external drain probe** and can include Coss/snubber displacement. Do not treat it as diode charge. Both body-diode branches (`i(v.xql.x1.v_sense2)` and `i(v.xqh.x1.v_sense2)`) are in the raw waveform from T1−100 ns through incoming command+250 ns; the CSV summarizes the incoming branch only. This single-transition current-source deck does not contain the preceding resonant half-cycle, so its outgoing diode history cannot establish physical stored-charge initial conditions for Qrr. `turnoff_model_dissipative_sum_j` is only the outgoing device's model dissipation over its command window; it is not total turn-on/recovery/diode loss.

## Use constraints for C2

The six driver times use TI UCC21550 Rev C page 10 characterized 50 kΩ 399/443/487 ns ratios, **ASSUMED** transferable to nominal 39 and 51 kΩ. They are not guaranteed min/max at either resistor. Installed R9/R17 39 kΩ resistor tolerance, a possible 51 kΩ resistor tolerance, and controller-inserted dead time are additional timing uncertainties not covered by the six values. The reference model is 27 °C, a constant-current tank surrogate, and has nominal placeholder board/gate/ESL inductances. Current reversal across dead time requires the actual A derated tank trajectory; this deck cannot determine it.

Classify event buses below **10 V as outside map**. Do not interpolate through a `no_pass_through_100a` or `nonmonotonic_sampled` row in the selected criterion, or infer a guarantee between sampled current points. At 10 V use the supplemental signed-VDS map to avoid counting a forward-clamped incoming switch as a hard Eoss event merely because its negative diode drop exceeds 0.5 V; use diode current and actual event trajectory for loss. A crossing bracket is numerically uncertain for events inside the bracket. When an A event lies in an unresolved region or needs accurate diode dwell, run its exact current and bus with the C1 runner on the relevant D1 matrix when available. Match the A event's signed leg current to direction before comparing the positive current magnitude. This reference deck has one leg at a time; the D1 coupled matrix must be applied separately to both physical legs.
