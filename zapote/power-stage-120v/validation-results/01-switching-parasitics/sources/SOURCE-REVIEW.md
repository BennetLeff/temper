# Source review for task 01

- Infineon CoolMOS CFD7 650 V SPICE archive: [official download](https://www.infineon.com/assets/row/public/documents/24/50/infineon-power-coolmos-cfd7-mosfet-650v-spice-simulationmodels-en.zip). The committed `validation-plan/sim-kit/models/fetch_models.sh` pins archive SHA-256 `5a6341084202debb0f8f230b8809c090434ea9526c8e0defe3d2e07a832ff48d` and extracted library SHA-256 `02ac6634f47c25be04e8de3c6eec4ec8cf403b659001b7f176c8f98bb6e9ce3b`. Both local ignored vendor files matched on 2026-09-27. The kit uses the exact `IPW65R018CFD7_L1` subcircuit. The vendor model is not copied into this result or committed.
- TDK B32652A0104K000: [official part page](https://product.tdk.com/en/search/capacitor/film/snubbering_pfc/info?part_no=B32652A0104K000), and its [B3265*A/G/J/T datasheet](https://product.tdk.com/system/files/dam/doc/product/capacitor/film/mkp_mfp/data_sheet/20/20/db/fc_2009/mkp_b32651_658.pdf), revision June 2026. The part page gives 100 nF ±10%, 1 kV DC, and 15 mm lead spacing. The series datasheet calls the family “very low inductance” on PDF page 2; a typical impedance-versus-frequency graphic appears on PDF page 38. No exact-part numeric ESL or self-resonant-frequency table was found. The text matches for ESL/LS on PDF page 77 are definitions in the symbols table. Thus this source does not provide a defensible numeric `LCAP` for all corners. The first local `curl` attempt failed DNS inside the sandbox; two approved network attempts to TDK's current URL and one to its official legacy mirror returned HTTP 403. A local datasheet SHA-256 could not be obtained; this is an unfulfilled source requirement, not a substituted value.
- TI UCC21550: repository `datasheets/ucc21550.pdf`, SHA-256 `f600571197e32da4b915f986da003d95d73294dd8e428d7a4e6dcc89bbe29207`. Its official URL is https://www.ti.com/lit/ds/symlink/ucc21550.pdf. The starter deck encodes typical ROL/ROH, but there is no switching result with board-bound parasitics in this report.
- Infineon IPW65R018CFD7: [official datasheet](https://www.infineon.com/assets/row/public/documents/24/49/infineon-ipw65r018cfd7-datasheet-en.pdf), consulted for model identity; no acceptance value is asserted from it in this blocked task. A local copy/hash would be required before using values from it for a verdict.
