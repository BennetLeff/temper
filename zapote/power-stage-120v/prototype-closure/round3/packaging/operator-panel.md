# Local pod operator controls — required startup interface

The pod requires its own **START PRECHARGE**, **RESET FAULT** and **STOP** controls, powered from the inlet module's local auxiliary supply. The existing controller's PS1 is downstream of the contactors, so it cannot be required to start precharge. Do not backfeed PS1 or an existing control rail from AUX to hide this dependency. The circuit/control implementation defines the precise sequence and interlocks.

Reserve three 22.5 mm nominal operator cutouts in the removable pod front at X60, X120 and X180, all Z230. Budget a 30 mm head diameter, 10 mm forward projection and 60 mm rear body/terminal depth for each. These are control-panel placement reservations; exact operator MPN, terminal boots, seals, rated contact blocks and hole tolerances remain to be selected. The placement is outside the fuse-door corridor and below the hot-zone guard. These controls have not been added to the STEP; the declared bounds must be checked with the actual purchased operator assembly.

START PRECHARGE initiates the local supervised sequence while the downstream controller is unpowered. RESET FAULT only acknowledges a fault when the control design's reset conditions are true; it must not automatically resume cooking or bypass precharge checks. STOP connects into the independent interruption/inhibit chain described by the energy/control design; a software message to the unpowered downstream controller is insufficient. Exact contact polarity, channel architecture and reset timing belong to that circuit review, not to this panel drawing.

Reserve labeled **INLET READY**, **FAULT** and **BUS PRESENT** indicators at X60/120/180, Z270, using isolated status sources where required. BUS PRESENT is information only: a dark lamp is not verification of discharge. Normal cooking controls stay on R4 after the inlet sequence completes; the external box remains an engineering instrument, not a second everyday cooking interface.

Keep the manual line switch separately at nominal X330/Z230. Its OFF state does not prove the main bus or the separate catch capacitor is discharged. Provide a label identifying both stored-energy nodes and the defined test points, with the test procedure in the first-unit traveler. Select button/indicator hardware and finish the door harness with a restrained service loop and a separate door protective bond before building a powered article.
