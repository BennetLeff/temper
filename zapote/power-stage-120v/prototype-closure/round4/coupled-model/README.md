# Round 4 joined power model and protection coordination

This packet implements a **runnable, two-way coupled differential-mode diagnostic**. It joins source impedance, auxiliary load/inrush sensitivity, the D22/native filter, precharge/bypass/proof, rectification, the native DC link, phase-shift bridge/tank, local catcher, voltage/current fault latching, finite gate delay and delayed source opening in one transient solve. The compiled portable firmware adapter supplies the conductance command. This is substantially more connected than round2's algebraic load or round3's disconnected initialized tank.

**It is not the final device/field/protection qualification model.** The component approximations below are explicit, and failed detailed-reference attempts are retained as incomplete. No nonzero commissioning current or new PCB release is granted.

## Reproduce

From the worktree root:

```sh
sh zapote/power-stage-120v/prototype-closure/round4/coupled-model/run.sh \
  output/temper-prototype-closure/round4/coupled-model/new-run crest_140
```

Use a fresh output directory; an existing directory is rejected. Optional second argument is one case name; optional third argument selects `joined.cir` rather than the default `reduced.cir`. The runner requires ngspice 45.2, builds standalone Rust without touching shared extension caches, runs its parser/model and coordination tests, and leaves `STATUS=INCOMPLETE` until all requested cases return every finite measurement exactly once. Raw decks and logs are retained. `SIMULATED_DIAGNOSTIC_ONLY` means numerical completion, not component qualification. A case may be intentionally **rejected by precharge** while still numerically complete.

`all` requests the complete exploratory matrix, **which has not passed as a batch**. Some ideal fault discontinuities abort ngspice. The preserved evidence includes those failures; do not silently drop them. `report.rs` packages individual completed receipts, rejects an aborted log masquerading as a result, hashes every deck/log, verifies the firmware CSV snapshot, and compares two timestep pairs only after proving the decks otherwise identical. Compile it with standalone `rustc --edition=2021` and pass the existing output root. It intentionally reports failed convergence rather than converting all simulated cases into passes.

## Circuit and implementation boundary

- D22 values remain2.2µF input X,4.7µF output X,4.7µF/3.9Ω damping,30kΩ bleed; native1µF X capacitors; two18µH differential-loop leakages,9mΩ winding-loop assumptions. Source is0.1Ω/20µH,60Hz. ESR35mΩ is assumed. Choke saturation/hot core loss, CM/Y-capacitance, MOV and EMI receiver are absent. No earlier RF margin transfers here.
- The default rectifier is a power-conserving DM two-port with an aggregate two-diode forward fit. It reflects DC current with AC polarity, so bus/load response changes line/filter behavior. `joined.cir` retains the explicit four-diode rectifier and four switch conductances. Neither uses a vendor-validated nonlinear GBJ/FET model.
- The default bridge applies a smoothed full-bridge squarewave and reflects its instantaneous tank current into the DC port. Following inhibit it returns energy through a passive-rectification approximation. Its effective conducting resistance is36mΩ, diode drop1.4V. It omits individual gate deadtime, nonlinear Coss, switching loss and cross-leg/Kelvin field matrices. The `DT` parameter belongs only to the detailed four-switch reference; no default-model deadtime result is claimed.
- Tank starts at **zero current and zero capacitor voltage**, nominal540nF, study20µH/2Ω with detuning cases. The hypothetical phase calibration inverts the series-RLC fundamental response; it is not a characterized pan map. The adapter itself still denies nonzero commissioning without real limits. This hypothetical override is explicit test stimulus, not installed firmware permission.
- `conductance-study.csv` is a byte copy of the firmware agent's export obtained by compiling the actual portable adapter. The source schedule has2Hz upward response,2000W/s cap and completed60Hz cycle updates for100/120/140Vrms,1500W study request/pan cap and25W auxiliary reserve. The final model shifts initial RUN from90 to135ms and slews each held update over1µs for numerical regularization. It applies a one-cycle RC estimate of squared whole-inlet current to reduce conductance above13.5A. **That estimator is not the firmware's exact completed-cycle RMS implementation**, so this is not a closed-loop executable-firmware co-simulation.
- Precharge uses selected11Ω. Before bypass at70ms, four valid absolute line-crest windows within36.667–70ms must accumulate at least0.8ms: bus≥95% line crest,|VPRE|<5V,|Ipre|<0.5A and catch>90% bus. Four ideal windows total approximately0.949ms. Correlated catch charging rejects an open catch fuse; an upper voltage limit alone cannot prove that path. The90% surrogate is not the supervisor's completed ADC algorithm/error budget. This is a sampled-window approximation to two complete valid cycles, not a test of the supervisor ADC circuit. Failed admission inhibits bypass and gates; it must not be called a reachable RUN result. Proof branch220Ω is enabled75–125ms only after bypass, implementing the final50ms proof allocation; RUN begins135ms. Exact proof/rail/mirror validation remains in the supervisor tests rather than being simulated as analog device circuitry here.
- All storage initially uncharged except the explicitly attempted charged-catch reclose. An initial catch above30V holds source contacts open. Faults latch; no automatic reclose exists. Study thresholds230V bus,250V catch and85A tank are provisional diagnostic values, not released limits. Gate delay2µs and20µs sensitivity are allocations, not measured worst cases for the complete detection chain.
- Source opening begins24ms after latched fault (or the scheduled command), with a100µs resistance transition and a400V piecewise arc-voltage **sensitivity assumption**. It removes new line energy without resetting bus/tank/catch states. It does not establish contactor interruption or arc safety.
- Catch47µF nominal is studied at42.3µF minimum,80mΩ total series resistance, generic diode forward fit and150pF junction capacitance. Route feedback requires1µH and3µH sensitivities: the final three external wires total842.186mm including fuse-to-diode, are not uniformly paired and contribute4.835mΩ nominal20°C copper resistance (6.451mΩ at105°C by the routing agent's temperature screen). These are sensitivity inductances, **not extracted inductance**;80mΩ includes assumed contacts/holder/diode resistance beyond copper. Fuse action is not invented; explicit open/short faults probe loss of catcher and bus feeding. The shorted-device reduction represents brief shoot-through until gate inhibition, not every possible welded-transistor topology.
- AUX25W is upstream of precharge but downstream of the shared source impedance. Its separate30A,1ms halfsine is an assumed sensitivity based only on a typical manufacturer peak, not a guaranteed inrush waveform. Cold reclose, warm inrush and supply hold-up need actual bounds. Earlier runs placed AUX at the ideal source and only reflected it into RMS; those are explicitly historical, not the final joined source model.

## Evidence and failed checks

Only batches named `joined-v3-*` use the final50ms proof, RUN135ms and shared source/AUX impedance. `all-results.csv` labels all other receipts historical. Older decks are still useful for failure discovery and sensitivity, but their numbers are not the final design's certified stresses. An incomplete batch can contain individually complete rows; the batch status remains visible in the index.

The final140Vrms startup at11Ω completes with197.054V bus peak,92.212V tank peak and19.589A tank peak over260ms (RUN135–210ms). Halving maximum timestep0.5→0.25µs changes every recorded metric by less than0.831%, passing the declared2% screen for **this case only**. The PC12.5 candidate completes with197.062V bus,92.441V tank and19.606A tank; precharge crest drop1.594V and qualification0.9493ms pass the modeled thresholds. These short-ramp points are not1500W steady-state tests or maximum permitted operating points.

The historical one-second, low-loss20µH/0.3Ω case with20µs gate delay and3µH catch reached497.87V tank and85.50A from zero initial storage. It used the hypothetical RLC phase map and85A diagnostic trip. That does not reproduce the earlier1580V initialized-tank diagnostic, establish a real pan operating envelope, or authorize85A. Its peaks have not passed timestep convergence.

The historical shorted-catch-capacitor case demanded about748A and6352A²s in the bus-fed path before mechanical isolation with fuse action deliberately absent. This is prospective, uninterrupted demand, **not fuse let-through**. Its0.25µs refinement aborted near the fault; the number is unconverged and cannot qualify or bound a protective part. Nonetheless it directly identifies why contactor opening alone is an inadequate semiconductor protection argument. Catch-local stored energy may bypass the upstream fuse entirely.

The low-loss historical case's tank integral changed19.4869→20.1799A²s on the exact same deck at0.25→0.125µs, a3.43% change, **failing the2% convergence screen** even though voltage/current peaks changed less than0.2%; its rectifier integral also changes3.10%. Older0.5→0.25µs comparisons also changed qualification logic and therefore are not pure timestep convergence. The detailed four-switch reference was terminated without a completed result; it provides no validation credit. No source/RF, thermal or dielectric margin is inherited across these boundaries.

## Design decisions

[Protection coordination](protection-coordination.md) records selected fuse data with their actual test conditions and the fail-closed capacitor admission calculation. It also rejects the thermally attractive88Ω precharge candidate under the present admission contract: filter reactive current prevents the required bus/drop qualification. The model therefore does not “solve” resistor stress by quietly allowing a rejected startup.

The remaining digital closure is precise: nonlinear vendor/device/TVS and actual protection-chain timing, native19 field matrices, exact supervisor analog/logic plus executable current-feedback co-simulation, source fault envelope/fuse/arc coordination, and an adopted precharge resistor with documented installed thermal/pulse limits. Exact capacitor50kHz hot application limits and actual coil/pan data remain separate supplier/physical inputs. Do not describe all of these as waiting only for assembled hardware.
