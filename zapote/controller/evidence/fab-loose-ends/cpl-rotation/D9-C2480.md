# D9 (SS14, LCSC C2480): JLC footprint orientation vs the KiCad `D_SMA` footprint (2026-10-18)

Source: `https://easyeda.com/api/products/C2480/components`, read in a browser tab (a script got HTTP 403). Package `SMA_L4.2-W2.6-LS5.0-RD_1`.
Same method as `audit.py` method B (JLC places the LCSC library footprint at the CPL rotation).

| | EasyEDA / JLC footprint (10 mil units, origin 3998.1, 3002.5) | KiCad `Diode_SMD:D_SMA` (mm) |
|---|---|---|
| pad 1 | x 3990.364 (left of origin by 7.736 = 1.965 mm), y on the centre line | x -2.0, y 0 |
| pad 2 | x 4005.836 (right by 7.736 = 1.965 mm) | x +2.0, y 0 |
| symbol | pin number 1 = **K** (cathode), pin number 2 = **A** (anode) | `Schottky1A40V`: K = pin 1, A = pin 2 |
| silk | filled region on the pad 1 side (cathode mark) | cathode band on pad 1 |

Pad centres agree within 0.04 mm (the pads differ in size: 1.52 x 1.68 mm there, 2.5 x 1.8 mm here). Pad 1 (cathode) is on the left and pad 2
on the right in both, so the offset is 0 degrees and the CPL rotation of D9 (0) is right. JLC's 3D preview is still the final check.
