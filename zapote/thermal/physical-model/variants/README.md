# Native-bound bridge contracts

These contracts were generated by the Rust `zapote-physical-contract` binary
from the retained native and manufacturing captures. Generation validates the
embedded board digest, bridge identity, four pad/net identities, manufacturing
pad and hole records, and computes a geometry fingerprint from the imported
neck records.

The 3 mm native and manufacturing files are owned by the bridge-connections
workstream and are retained in that candidate directory. The contract is
deliberately source-unverified (`cached_primary_text`); use the canonical
archived Yangjie PDF and the byte-bound replay before promoting a source claim.
Neither contract is a thermal acceptance result until the real joint-terminal
FEM run, mesh checks, and PFC waveform assessment are retained.
