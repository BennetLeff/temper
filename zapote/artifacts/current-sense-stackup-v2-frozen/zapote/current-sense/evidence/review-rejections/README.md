- Native extractor independently reimplemented connectivity from immediate neighbors, emitted a different schema from UnitNativeEvidence, and omitted filled zone geometry. Coordinator required reuse of the existing verified assembly_geometry/native_measure path and real-board comparison.
- Circuit draft treated a resistor leading to a bias divider as parallel with the divider Thevenin resistance; absent a bypass/buffer, those resistances form a series path to AC ground. Coordinator required a corrected actual graph and independent model evidence before source freeze.
