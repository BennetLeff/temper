# Temper donor rule inventory

Audited at `6226537c9ae2a30e41a5fbd71c656cda94ef138e`. This lists all 27 default registered rules and the one deliberately unregistered ERC stub. None of these complete rule types is linked into Zapote. Partial overlap is listed explicitly. Source review is not a fresh donor-board execution.

The [JSON snapshot](inventory-2026-09-12.json) records exact source hashes, registration, test locations, supplementary donors and unit report IDs. Batch labels refer to the [next-port sequence](README.md#next-port-sequence).
