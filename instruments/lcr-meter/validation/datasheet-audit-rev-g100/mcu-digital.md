# Datasheet audit, Rev G100: group `mcu-digital`

Scope: U1 RP2040 (power pins, internal 1V1 regulator and its caps, decoupling, RUN, TESTEN, ADC pins, every GPIO against
`firmware-rev-e/src/pins.h` with `LCR_REV_G=1`), U2 GD25Q16ESIGR with C11 / R7 / R8 / R13, Y1 ABM8-272-T3 with C12 / C13 / R10,
USB D+/D- (R3 / R4, routing), SW1 / SW2 (TS-1088) with R9 / C14, J4 SWD, debug and rail LEDs D15-D20 with R113-R118, the test
pads, and the RP2040 ADC inputs (JACK_HC / JACK_LC on GPIO28 / 29, MON12 / MON_N12 on GPIO26 / 27).

Method: `validation/datasheet-audit-rev-g100/parts.txt` / `nets.txt`; `cad/routing.json` and `cad/temper-lcr.kicad_pcb` read with
KiCad's Python (read-only). Track distances below are **routed copper path lengths** (Dijkstra over the net's track graph from the
pin pad to the other pad, vias included), not straight-line distances, unless marked "direct". The same scripts were run on Rev F
(`study/lcr-in-box`) for comparison. Scratch scripts: `scratchpad/datasheet-audit-g100/mcu-digital/{graph.py,path.py,prox.py}`.
Nothing in the repository was modified apart from this file.

Stack-up used for estimates: JLC04161H-7628 (docs/rev-f-plan.md), F.Cu over In1 at 0.21 mm prepreg. In1 is a solid GND plane
with no tracks (checked: 0 In1 track segments); In2 and B.Cu are GND pours cut by 222 / 249 track segments.

Datasheet shorthand:
- **DS** = RP2040 Datasheet, build-date 2025-02-20, build-version 3184e62-clean (`sources/new/RP2040-datasheet.txt`).
- **HDG** = Hardware design with RP2040, Release 2, build date 20/08/2026, build 0444806419d7 (`sources/new/RP2040-hardware.txt`).
- **GD** = GigaDevice GD25Q16E datasheet, rev 1.1, 2020-04-15 (`sources/new/GD25Q16E.txt`).
- **ABM8** = Abracon ABM8-272-T3, drawing 456603 rev IR, issued 16 Nov 2023.
- **KT** = Kento KT-0603R approval sheet A.0, 2018-12-06.
- **TS** = XunPu TS-1088-ARXXXXX drawing, rev A.

## 2. Versus the Rev F audit (`validation/datasheet-audit-rev-f/mcu-digital.md` and README dispositions)

**Rev F got wrong or missed:**
1. **M3 / N6 (VREG_VIN, ADC_AVDD decoupling) were measured as direct distances.** Rev F gives "VREG_VIN (44) has 1 uF X5R C5 2.6 mm away" and "pins 42, 43, 44, 48, 49 share C5 at 3.8/2.7/2.6/2.8/3.0 mm". On the routed copper (identical on Rev F, 13.9 mm), C5 is 13.8 mm from pin 44 and serves pins 48 / 49. This turns a "MISSING (minor), accepted" into the VIOLATION MD-1 against DS 2.10.1's "must … close".
2. **M2** gives pin 50 → C8 as 6.3 mm and pin 23 → C9 as 5.8 mm (direct). By track they are 9.5 mm and 7.5 mm. The finding itself stands, as MD-2.
3. **R3 (tVSL)** concluded "R9/C14 is the thing that makes it work, so it is functionally required". The bootrom retries the flash boot 128 times over about 0.5 s (DS 2.8.1.3.1), so a first probe before tVSL is harmless. This is downgraded to OK-NOTE N1. The bring-up scope check is no longer needed for this reason.
4. **USB series resistors:** Rev F lists "R3/R4 27 R" as fine without checking placement. They are 7.8 / 8.3 mm of track with two vias from the pins (HDG "placed close to the chip"), MD-8, and they were the same on Rev F.
5. **EP via count:** Rev F N7 says 9 vias. G100 has 8 (fine).

**Rev F got right (verified, kept):** GPIO13 is fault-tolerant (DS Table 615), so USB_SENSE unpowered is in spec (N4). MON12 / MON_N12 power-down clamping (R1, now MD-5). Y1 chamfer (M1). I2S edges (R5: lengths unchanged in G100, BCLK 69.1 mm). GD / boot2 compatibility (N1 there, N2 here). LED arithmetic (N4 there).

**Changed by Rev G / G100:**
- **GPIO28 / 29** went from the UART header J6 to the jack senses (Rev G). Rev F R2 (5 V adapters on J6) is closed. The pins are non-FT ADC inputs: new findings MD-3 (leakage versus the close / trip thresholds) and MD-4 (unpowered clamp excursion).
- **GPIO15** went from spare to ISO_DRIVE (fail-safe, N3). Rev F debug D4 proposed GPIO15 as a trigger pad, but only GPIO24 / 16-21 are left.
- **J5 dropped (G100):** Rev F R2's VTREF concern is closed, but SWD lost its only GND pin: MD-10.
- **RUN** re-routed: R9 / C14 went from 24 / 27 mm to 68 / 74 mm, along the board edge and 42.8 mm beside MON12 (MD-6).
- **R7 / R8** moved from the flash (5.5 / 9.8 mm from U2.1) to U1 (22 mm from U2.1): MD-7.
- **U2** moved west of U1's south side: C11 → U2 VCC improved from 3.95 to 2.05 mm. QSPI SD1 / SD2 grew from 19.5 / 16.7 to 26.9 / 25.0 mm (In2), and CLK shrank from 20.7 to 14.8 mm. Timing is still trivial (N2).
- **U1 core decoupling, crystal and USB copper** are unchanged from Rev F (same relative placement and lengths), so MD-1 / MD-2 / MD-8 / MD-9 are inherited. Rev F README disposition "M2, M3: revisit at the next respin of the U1 area" applies now, because G100 re-routed the U1 south side anyway.
