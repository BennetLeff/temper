# Rev B implementation scope

Approved in this conversation on 2026-10-20. Keep the instrument under `instruments/differential-probe`; preserve the stage-53 hardware baseline and unrelated checkout changes.

1. Add a real, documented fine-adjustment capacitor to each low leg, with identical placement and grounded adjustment structure where supported. Retain coarse C0G selection and leave adjustment range around the nominal compensation point. Record shield access and tool-withdrawal checks.
2. Make the subtractor a fixed ×2 stage. Add a fixed ×5 stage and select its output or the ×2 output before the common filter/output buffer. No range contact is in an amplifier feedback loop. Include a defined DC return during switching and account for the unused fine stage saturating during valid wide-range operation. Select parts and filter values against the whole cascade, including source resistance and loading.
3. Warn at the initial operating envelope: each tip below the ±1.5 kV boundary, and the selected signal below the ±1.5 V output boundary (±1.5 kV wide / ±300 V fine). Derive tolerance margins; the LED is an operating-limit warning, not evidence of completed qualification or capture of every short transient.
4. Compact the board while retaining equal divider/tap geometry, controlled shield routing, and all HV clearances. The extended spacing envelope simultaneously requires `|V+| ≤ 3 kV`, `|V−| ≤ 3 kV`, and `|V+−V−| ≤ 3 kV`. It excludes 6 kV opposing-tip survival. Under intact divider sharing, opposite-leg node spacing uses the larger node rank rather than the sum. Same-leg rank differences and tip-to-earth rules stay unchanged. Final dimensions are determined by checked placement and routing; halving area is not assumed.
5. Preserve Rev A and final Rev B as scoped commits on `codex/differential-probe-revb`, without changing the shared checkout's branch/index. Correct the CT analysis and provide stage-specific applicability patches for historical documents; do not modify or silently repin the stage-53 board.

Acceptance: regenerated native schematics/BOM; zero ERC violations; routed canonical PCB; zero native DRC violations and unconnected items under the documented rules; schematic-to-PCB parity and divider geometry checks; native negative controls for spacing rules; layer and 3D inspection; current design/qualification notes and saved Git recovery points. No physical CMRR, bandwidth, withstand, recovery or thermal qualification is implied by these digital checks.
