### Canary Protocol

For each family without an existing expected-fail test, a deliberate defect was planted:

1. Modify the test assertion to create a false condition
2. Rebuild the wasm32 module
3. Run the test and verify it traps (WebAssembly.RuntimeError)
4. Restore the original source

All five families (drc, emc, placement, routing, safety) were verified to trap under planted defects on 2026-08-07 at commit `14979d633`. The integration family is transitively covered — its `empty_board_zero_violations` test calls `run_all` on the default registry, and any rule-family violation injected into the registry would cause it to fail.
