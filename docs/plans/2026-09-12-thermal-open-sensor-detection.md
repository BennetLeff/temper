# Thermal Rev B: detect disconnected probes in hardware

User-approved behavior: either overtemperature or an open/shorted probe asserts each channel's existing active-high fault output. The thermal board owns detection; a later interlock owns latching, power inhibition and reset. No firmware dependency or direct tie between push-pull outputs.

Keep the heatsink 85/70 °C and coil 120/100 °C nominal trip/release targets. Change coil bias to 10kΩ and retune its loaded feedback network (20k top, 8.06k bottom, 42.2k feedback) to create cold/open voltage separation. Add TLV9031DBVR per channel, IN+ to sense, IN− to shared OPEN_REF. Set OPEN_REF using 1.21kΩ top / 100kΩ bottom, both 1%. Combine each original hot comparator and open comparator through an SN74LVC1G32DBVR. Keep hot hysteresis feedback connected to HOT, never the combined FAULT. Add four local 100nF bypass capacitors.
