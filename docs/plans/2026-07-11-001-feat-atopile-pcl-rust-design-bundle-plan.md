# Typed Rust Atopile + PCL Design Bundle Boundary

## Summary

Add a dedicated Rust crate, `temper-design-bundle`, that owns the validated
input boundary for placement, routing, and validation. It imports a versioned
Atopile export, the KiCad identity inventory, `NET_NAME_MAPPING.md`'s
machine-readable successor, and PCL YAML into one deterministic `DesignBundle`.
The crate builds as `rlib` and `cdylib`, with a minimal PyO3 adapter.

This is a strangler-fig boundary: no existing placer/router is rewritten. The
new bundle is exercised in parallel against the Temper board, produces a
golden normalized artifact, and becomes the only allowed input to later Rust
placement/routing stages after parity is established.

## Architecture

```text
Atopile export ─┐
KiCad inventory ├─> Rust import + identity resolution ─┐
net mapping ────┤                                      ├─> DesignBundle
PCL YAML ───────┴─> Rust PCL parser + safety merge ────┘       │
                                                               ├─> JSON golden / PyO3 DTO
                                                               └─> future place/route/validate
```

`DesignBundle` is immutable after construction. Stage-specific results are not
added to it; later work introduces `PlacedDesign`, `RoutedDesign`, and
`ValidatedDesign` wrappers around it.

## Implementation Units

### U1 — Crate and canonical domain types

**Requirements:** R1, R4

**Files:**
- Create `packages/temper-design-bundle/Cargo.toml`
- Create `packages/temper-design-bundle/src/lib.rs`
- Create `packages/temper-design-bundle/src/model.rs`
- Create `packages/temper-design-bundle/src/error.rs`

**Work:** Define strongly typed IDs (`ComponentId`, `NetId`, `ZoneId`,
`ConstraintId`), units in millimetres, `BoardSpec`, `NetClass`, `SafetyDomain`,
`Stackup`, provenance hashes, constraint origins, and immutable `DesignBundle`.
Reject NaN/infinite/negative dimensional values at constructors. Use `serde`
with explicit schema versions; never deserialize free-form YAML directly into
internal types.

**Tests:** Rust unit tests for invalid dimensions, duplicate IDs, stable IDs,
and provenance equality.

### U2 — Versioned Atopile export and identity inventory

**Requirements:** R2, R5

**Files:**
- Create `packages/temper-design-bundle/src/atopile.rs`
- Create `packages/temper-design-bundle/src/identity.rs`
- Create `elec/exports/temper.design-input.v1.json`
- Create `elec/exports/net-name-mapping.v1.yaml`
- Create Rust fixtures under `packages/temper-design-bundle/tests/fixtures/`

**Work:** Define a small JSON export contract rather than parsing `.ato` files.
The initial committed fixture contains only information required by the bundle:
components, signals, net classes, safety/thermal/mechanical rules, and stackup.
Convert the current markdown net mapping into reviewed YAML with explicit
Atopile signal, canonical KiCad net, and optional aliases. Load a KiCad
inventory through a narrow DTO generated by the existing Python parser.

**Tests:** Missing/ambiguous mapping, unmapped KiCad net, duplicate canonical
net, and deterministic resolution tests. The original markdown remains
human-facing documentation and must be checked against the YAML mapping.

### U3 — Rust PCL parsing and constraint origin model

**Requirements:** R3, R4, R5

**Files:**
- Modify `packages/temper-constraints/src/constraints.rs` or move shared PCL
  types to a dependency-free `temper-pcl-ir` crate if ownership cycles require it
- Create `packages/temper-design-bundle/src/pcl.rs`
- Create `packages/temper-design-bundle/src/constraint_merge.rs`

**Work:** Parse the supported PCL YAML schema into typed constraints with stable
ID, tier, rationale, references, and `AuthoredPcl` origin. Preserve the existing
PCL enum's exhaustive dispatch property. Resolve every component, zone, net,
and loop reference against the canonical graph before returning a bundle.

**Tests:** One fixture per currently supported constraint variant; unresolved
reference and malformed-unit failures. Cross-check accepted Temper PCL YAML
against the existing Python PCL parser until the Rust parser is canonical.

### U4 — Atopile-derived safety constraints and strict merge

**Requirements:** R5, R6

**Files:**
- Create `packages/temper-design-bundle/src/derive.rs`
- Modify `packages/temper-design-bundle/src/constraint_merge.rs`

**Work:** Derive safety floors from Atopile net classes and inter-domain rules:
trace width, clearance, creepage, required isolation slots, board dimensions,
and stackup constraints. Merge derived and authored constraints by canonical
subject and metric. Permit stricter authored rules; reject weaker rules and
incompatible scopes with both origin diagnostics.

**Tests:** `proptest` for monotonic safety merge; direct examples for 4 mm vs
6 mm rejection and 8 mm vs 6 mm acceptance; deduplication determinism.

### U5 — Deterministic interchange and PyO3 adapter

**Requirements:** R7, R8

**Files:**
- Create `packages/temper-design-bundle/src/serialize.rs`
- Create `packages/temper-design-bundle/src/python.rs`
- Add Python adapter `packages/temper-placer/src/temper_placer/io/design_bundle.py`
- Add package build/CI wiring following `temper-quality-oracle`

**Work:** Serialize sorted normalized output with stable IDs, provenance, and
origins. Expose `build_design_bundle(...)` through PyO3. Map Rust errors to
structured Python exceptions without lossy string parsing. The adapter accepts
paths/bytes and returns an immutable DTO or a JSON artifact; it does not expose
mutable dict internals as the pipeline state.

**Tests:** Rust serialization snapshot; PyO3 pytest happy path and all fatal
error categories; import/build check in CI.

### U6 — Temper parity fixture and adoption gate

**Requirements:** R9

**Files:**
- Create `packages/temper-design-bundle/tests/temper_bundle.rs`
- Create `packages/temper-placer/tests/rust_integration/test_design_bundle.py`
- Create `packages/temper-design-bundle/tests/golden/temper.design-bundle.json`
- Update relevant developer documentation

**Work:** Build the committed Temper bundle from Atopile export, mapping, KiCad
inventory, and PCL. Compare to a reviewed golden normalized artifact. Add a
CI gate that runs Rust tests and PyO3 integration tests. Do not switch the
production placement command until this gate proves parity and no unresolved
constraints exist.

## Dependency Order

`U1 → U2 → U3 → U4 → U5 → U6`.

U3 must decide whether `temper-constraints` is shared directly or whether its
IR moves into a leaf crate before implementation. Do not duplicate the
constraint enum in `temper-design-bundle`.

## Verification

```bash
cargo test --manifest-path packages/temper-design-bundle/Cargo.toml
uvx maturin develop --release --manifest-path packages/temper-design-bundle/Cargo.toml
uv run pytest packages/temper-placer/tests/rust_integration/test_design_bundle.py
```

CI must additionally reject a changed Atopile export, mapping, PCL YAML, or
KiCad inventory when the golden bundle was not intentionally reviewed and
updated.

## Risks and Mitigations

- **Type drift with existing PCL/Rust constraints:** share or extract the IR;
  never mirror it.
- **Atopile export instability:** version the DTO and fixture; reject unknown
  schema versions.
- **False parity with a broken Python reference:** assert direct invariants and
  known safety floors, not only Python/Rust equality.
- **Premature production cutover:** preserve the existing Python path until U6
  proves the new boundary on the real Temper artifacts.

## Out of Scope

No router/kernel port, CP-SAT migration, Atopile compiler implementation, or
legacy-loader deletion is included. Those become follow-on plans after the
bundle boundary is accepted.
