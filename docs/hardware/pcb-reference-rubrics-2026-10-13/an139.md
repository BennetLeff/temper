## What the source actually teaches

Kueck compares the buck's on and off paths. The highest-edge-current loop is their *difference*: only those branches abruptly take or release the switched current. For the buck example that loop closes through the nearest input capacitor and switching devices. A path carrying large load current can be thermally critical while a smaller loop has greater high-frequency radiation. The author associates EMI with effective magnetic loop area and inductance, and demonstrates that a nearby continuous copper plane can lower loop inductance. The 10 cm square loop experiment in Table 1 reports 187 nH without a plane and 13 nH with a plane 0.12 mm away; these are results for **that** test structure, not a target for Temper. [PDF pp. 1–4, Fig. 1, Table 1, Figs. 3–6]

The plane carries either induced mirror current or an intentional return current. A close plane helps suppress external magnetic field, yet the induced current develops high-frequency voltage across that copper. Thus a “shield” can become a noise-coupling path for a sensitive via or filter return placed directly in its active region. The author prefers a nearby, solid layer and places quiet connections outside the hot-loop mirror-current region. An active return in the closest layer is even more effective where the electrical topology allows it. These choices must still preserve insulation and creepage. A copper shield cannot be added beneath a high-voltage node merely to imitate a low-voltage buck illustration. [PDF pp. 3, 11–14, Figs. 4–5, 25–27]

The note treats driver supply and gate loops separately from the main switching loop, then addresses sense-pair reception, filter reference location and measurement. Its specific plots (roughly 20 dB difference in one simulated LT8610 example; conducted spectra for LT8610/11) explain ranking in those examples only. Its LTspice warning is explicit: functional models omit board and component RF parasitics. [PDF pp. 6–10, 13, Figs. 14–23, 28–29]

## Scoring contract for later evidence

Score each applicable criterion independently. **0** = a demonstrated violation of a defined applicable functional, insulation, thermal or EMI requirement; **1** = a concrete serious concern with an identified physical mechanism and no adequate mitigation evidence; **2** = documented geometry and design rationale support the choice, but the required simulation, measurement or margin verification is pending; **3** = design evidence plus relevant bench/EMI or independently validated-model evidence shows the required margin across intended operating cases; **U** = essential evidence is missing; **NA** = a written topology-specific reason shows the criterion truly inapplicable. Stop the assessment if identity does not match the selected candidate. A good-looking render alone is insufficient for 2; that state requires the stated supporting rationale and evidence. Do not average scores into a release or readiness result; the eventual reviewer should keep safety/insulation, thermal and EMC evidence separate. The common rules take precedence over the shorthand cues below: an observed overshoot, spectral change or ground bounce is not a failure unless it violates a defined requirement. Evidence must name the exact board hash, source schematic revision, operating mode and measurement setup. A DRC result is useful but cannot prove return-current distribution or EMC.

### Switching-current geometry

**AN139-01 — Map every bridge state before naming a “hot loop.”** **Question/evidence:** For both diagonal drive states, dead time, commutation, startup, fault turn-off and any freewheel or resonant interval, where does current flow from the local DC-link capacitor through each switching device, antiparallel diode, snubber, tank and return? Provide a marked schematic and top/inner-layer path overlay, including current direction and transition time. **Physics/advice/trade-off:** Derive the *difference* between adjacent states: abrupt current steps select the high-di/dt conductors. Optimize those loops while retaining enough copper and device spacing for heat, service and insulation. The buck's red/blue/green trace must not be pasted onto a full bridge. **Cues:** 1 if any commutation state lacks a defensible path; 0 if a measured overshoot/EMI event traces to a missed loop; 2 with complete state maps and physical path review; 3 after relevant switching waveforms/near-field corroboration. [PDF pp. 1–2, Fig. 1; p. 4, Fig. 6; p. 5, Fig. 8]

**AN139-02 — Local DC-link closure at both bridge legs.** **Question/evidence:** Which capacitors supply each edge current, and do their positive/negative terminals close short, low-impedance paths through each leg? Show pad-to-pad copper, vias, mounting inductance and actual capacitor impedance over relevant frequencies. **Advice/trade-off:** Place the appropriate low-ESL local capacitance next to the devices and keep both polarities close; bulk energy storage farther away serves a different frequency range. Moving the capacitor closer can crowd gate, creepage and heatsink regions, so compare quantified loop inductance and clearances. **Cues:** 1 for a visibly detoured local return or distant only-bulk capacitance; 0 for attributed destructive overshoot/failed limits; 2 for loop geometry and component rationale; 3 for waveform/EMI margin across current and temperature. [PDF pp. 1–3, Figs. 1–4; p. 10, Fig. 23]

**AN139-03 — Minimize effective loop area, not merely trace length.** **Question/evidence:** For each mapped high-di/dt loop, do forward and return paths run adjacent or above/below one another, without creating a large enclosed magnetic area? Estimate loop area or inductance using the actual layer stack and vias; compare alternative placements. **Advice/trade-off:** Shorter conductors often help, but the placement of the return path matters more than a one-dimensional length metric. Keep adequate conductor width, current capacity and heat spreading; an arbitrarily narrow trace used to “shrink” a loop can worsen loss and temperature. **Cues:** 1 for separated return paths or unexamined broad loops; 0 for demonstrated coupling/overshoot from the geometry; 2 for a state-specific area/inductance comparison; 3 for correlated measurement. [PDF pp. 1, 3–4, Table 1, Figs. 1, 5–7; pp. 15–16, Fig. 31]

**AN139-04 — Control the switch-node copper deliberately.** **Question/evidence:** Identify each bridge midpoint and other high-dv/dt islands, their area, layer reach, parasitic capacitance to quiet circuits, chassis, coil and heatsink, plus thermal function. **Generalization:** AN-139's central examples concern magnetic high-di/dt loops; minimizing capacitive electric-field coupling at an isolation barrier is discussed separately. The source does not prescribe a universal switch-node area. **Advice/trade-off:** Avoid gratuitous midpoint copper or proximity to sense/control paths while retaining necessary current capacity and device cooling. A smaller node can raise resistance and temperature; a broad plane can increase capacitance and common-mode current. **Cues:** 1 for large unexplained node extension toward quiet or touch-related structures; 0 for measured common-mode/functional harm; 2 for quantified parasitic/thermal trade; 3 with measured margin. [PDF pp. 1–4, 10, 14, Figs. 1, 23; Appendix A]

**AN139-05 — Preserve a close mirror-current path where permitted.** **Question/evidence:** Does the stack provide a continuous conductor beneath each permitted high-frequency loop, at a known dielectric distance, without slots cutting across the image-current route? Mark the exact layer under each path and distinguish induced shield current from intentional return current. **Advice/trade-off:** A close plane can lower inductance and field; it can also carry RF voltage and create capacitive coupling. Its net, copper extent and spacing must pass the board's isolation/creepage strategy. Neither “more ground” nor “four layers” alone earns a pass. **Cues:** 1 for a plane split beneath a fast loop or unexamined coupling; 0 for proven EMI/safety failure; 2 for stack and current-path evidence; 3 for field/EMI and insulation verification. [PDF pp. 3, 11–14, Table 1, Figs. 4–5, 25–27]

**AN139-06 — Keep quiet ground attachments out of the hot-loop shield region.** **Question/evidence:** Where are controller ground, sense returns, filter capacitors and plane-stitching vias attached relative to the predicted mirror-current path? **Advice/trade-off:** Place quiet attachments in an electrically and geometrically quiet area and route their references intentionally. A local plane under a switching loop may shield distant circuitry while carrying enough eddy current to create RF voltage at an ill-placed via. Avoid a blanket plane split that forces a worse return detour; the quiet connection point is the actual design variable. **Cues:** 1 for quiet vias inside an unassessed loop image; 0 for correlated ground bounce or false triggering; 2 for a return map; 3 after noise measurements. [PDF p. 3, Fig. 5; pp. 12–14, Figs. 26–27]

**AN139-07 — Keep high-current thermal paths compatible with RF geometry.** **Question/evidence:** Are power traces/copper pours sufficiently wide and thermally relieved without expanding the high-di/dt loop or switch-node capacitive footprint? Show current-density/temperature estimates plus loop geometry. **Advice/trade-off:** Wide, short conductors reduce loss and inductance, but location and return pairing determine loop radiation. Local heatsinking or layers may be preferable to copper extending toward sensitive areas. **Cues:** 1 for an EMI-driven neck-down or an unexplained broad noisy pour; 0 for exceeded temperature or measured EMI mechanism; 2 for combined electrical/thermal analysis; 3 for full-load thermal and waveform evidence. [PDF pp. 1, 3–4, Table 1; pp. 19–20, Appendices C–D]

### Drivers and sensing

**AN139-08 — Close each low-side gate-charge loop.** **Question/evidence:** Trace driver supply capacitor → driver output → gate → Kelvin/source return → capacitor, including package and via paths. Show the real source reference and switching current sharing. **Advice/trade-off:** Keep source return paired with gate drive and local decoupling; do not assume power ground is quiet at RF. Kelvin source routing may cost board area and pins but protects gate voltage against shared source inductance. **Cues:** 1 for a long/shared high-current source return; 0 for measured false turn-on or gate overstress; 2 for mapped loop and driver data; 3 for scoped gate-source margin across switching states. [PDF pp. 8–9, Figs. 18–19]

**AN139-09 — Close each high-side floating-driver and bootstrap loop.** **Question/evidence:** Identify supply/boot capacitor, high-side gate path, switch-node return and bootstrap recharge path for both legs. Include the chosen driver's exact architecture: bootstrap, isolated supply or other. **Advice/trade-off:** Pair gate and return close together; place the local storage capacitor at the driver and minimize its recharge path. A tight path can be constrained by creepage and high-voltage copper; preserve both. **Cues:** 1 for a floating return routed far from its gate or a distant capacitor; 0 for measured missing/erratic gate drive; 2 for path map and clearance review; 3 for measured VGS/driver supply margin. Mark bootstrap-specific subitems NA only if the hardware uses a different supply. [PDF p. 9, Figs. 20–21]

**AN139-10 — Treat driver-supply decoupling as a separate AC loop.** **Question/evidence:** Map the local driver rail, its decoupling capacitor and driver ground for every rail; measure or model droop and bounce. **Advice/trade-off:** It may carry less RF energy than the main power loop in Kueck's one example but can still disturb current sense and switching timing. Give it a short local return without bonding a sensitive reference into the active power-loop image. **Cues:** 1 for remote decoupling/shared return with no analysis; 0 for actual driver UVLO, jitter or nuisance trip; 2 for physical path and cap impedance; 3 for measured rail margin. The note's roughly 20 dB example is no general ranking. [PDF pp. 6–8, Figs. 14–17]

**AN139-11 — Route current-sense inputs as a small receiving loop.** **Question/evidence:** Show exact sense pickup points, sense+/sense− routes, return, filter and amplifier location. Does the pair avoid or cross the power-loop field; is it Kelvin-connected to its element? **Advice/trade-off:** Couple the pair geometrically and use an intervening continuous shield where permitted. Filter at the higher-impedance receiver, then verify bandwidth and fault-detection delay; excess filtering can hide real faults. **Cues:** 1 for single-ended detour, non-Kelvin pickup or crossing an active loop without evidence; 0 for measured duty jitter or false protection; 2 for topology/route/filter analysis; 3 for noise and protection timing margin. [PDF p. 10, Fig. 22]

**AN139-12 — Keep control and measurement references out of fast-field paths.** **Question/evidence:** Where do feedback, thermal, zero-crossing, coil-current and microcontroller references travel relative to gate and power loops? Which have differential routing and which rely on a plane? **Generalization:** AN-139's shunt receiver example establishes magnetic-loop susceptibility; each Temper signal needs its own bandwidth/impedance assessment. **Advice/trade-off:** Pair susceptible lines, keep their loop area small, place filtering at the receiver when appropriate and protect required signal bandwidth. **Cues:** 1 for an exposed sensitive route with no coupling analysis; 0 for observed jitter or false control action; 2 for signal-by-signal layout review; 3 with noise-injected and operational evidence. [PDF pp. 9–10, Figs. 18–22]

### Filter, magnetic coupling and interfaces

**AN139-13 — Establish a quiet filter boundary and return.** **Question/evidence:** Mark the noisy bridge side, quiet supply/harness side and every input filter capacitor return. Does the return connect at the same boundary traversed by the supply current, or does it pull RF through quiet ground? **Advice/trade-off:** Give the high-frequency filter a defined reference and keep its noisy and quiet sides physically separated. A via-stitch ring is one option in the source, contingent on safety spacing, chassis strategy and actual current paths. **Cues:** 1 for a filter capacitor grounded inside the active hot-loop image or bypassing the series element; 0 for measured conducted EMI caused by the topology; 2 for boundary and return map; 3 for LISN/near-field evidence. [PDF p. 14, “EMI Optimization”]

**AN139-14 — Make the filter path pass through its capacitor pads.** **Question/evidence:** Do both the outgoing and return conductors encounter the intended shunt element with minimal series lead/trace inductance? Are small low-ESL ceramics at the high-frequency point while larger energy capacitors support lower frequencies? **Advice/trade-off:** A component on the schematic may be electrically bypassed by an easier copper path. Shorter/wider geometry or reverse-geometry packages can reduce ESL but can increase cost, assembly complexity or voltage-rating constraints. **Cues:** 1 for a branch-stub connection at the highest-frequency filter point; 0 for demonstrated filter ineffectiveness; 2 for impedance and geometry evidence; 3 for measured insertion/conducted margin. [PDF p. 14; p. 20, Appendix C]

**AN139-15 — Check magnetic coupling around filter inductors.** **Question/evidence:** Where are line/filter inductors or chokes relative to the induction coil, resonant inductor/transformer and bridge current loop, and what are their field axes and shields? **Advice/trade-off:** Keep filter magnetics apart from strong fields, rotate or shield when measurement supports it, and test at operating current because coupled flux can bypass the intended filter attenuation or saturate a core. The source specifically warns of transformer action between a main and filter inductor; it supplies no universal spacing or orientation angle. **Cues:** 1 for adjacent aligned magnetics without coupling evidence; 0 for observed saturation or attenuation loss; 2 for field/coupling estimate; 3 for measured filter performance under load. [PDF p. 14, “EMI Optimization”]

**AN139-16 — Evaluate conducted and common-mode routes separately.** **Question/evidence:** What are the differential path through supply/harness conductors and the common-mode paths through capacitances to heatsink, coil, enclosure and nearby planes? Identify which filter element addresses each route. **Generalization/limit:** AN-139 explicitly discusses close input decoupling and common-mode chokes for a *flyback*, while Appendix A distinguishes magnetic AC loops from electric-field coupling at an isolation barrier. Temper's full bridge needs its own path model; a flyback choke prescription is not automatic. **Cues:** 1 for a single generic “EMI filter” claim with no path evidence; 0 for measured limit failure attributed to a route; 2 for separate path and impedance model; 3 for measured modes. [PDF p. 6, Fig. 13; p. 14, Appendix A]

**AN139-17 — Verify filter/source impedance and stability.** **Question/evidence:** Across startup, switching frequencies and load modes, does the chosen line filter and DC-link network resonate with the actual source impedance or bridge input behavior? Measure impedance or transient response, and document damping. **Generalization:** This is an engineering extension, not a worked AN-139 criterion: the note's simulated L2 deliberately isolates an ideal zero-impedance source, and its LISN imposes a repeatable test impedance. **Advice/trade-off:** More filter capacitance or inductance can improve one EMI band while worsening resonance/inrush; use realistic source and harness models before selecting damping. **Cues:** 1 for filter sizing from a source-free schematic only; 0 for observed oscillation/overstress; 2 for source/load network analysis; 3 for transients and conducted margin. [PDF p. 7, Fig. 17; pp. 21–22, Fig. 41]

### Insulation, evidence and test

**AN139-18 — Do not trade insulation for a close image plane.** **Question/evidence:** At every HV or isolation boundary, does the nearest return/shield satisfy the pin-specific clearance, creepage, dielectric, partial-discharge and manufacturing rules applicable to the candidate? Quantify parasitic capacitance across the boundary. **Advice/trade-off:** The note's near-plane benefit is demonstrated in a nonisolated loop; Appendix A explicitly says electric-field coupling across an isolation barrier calls for separation and less facing conductor area. Where these conflict, the required insulation rule controls, and another return strategy must be devised. **Cues:** 1 for unexamined plane overlap across an isolation region; 0 for failed spacing/dielectric rule; 2 for rule and capacitance analysis; 3 for appropriate production-grade verification. [PDF pp. 3, 12–14, Table 1, Appendix A]

**AN139-19 — Use field/impedance evidence for proposed layout improvements.** **Question/evidence:** For any moved capacitor, narrowed switch node, layer change or filter addition, is there a before/after map of loop inductance, return path, overshoot, temperature and EMI proxy at the same operating point? **Advice/trade-off:** AN-139 ties layout, function and EMI, but a narrower magnetic loop can alter capacitance or heating. Compare more than one metric; distinguish layout causality from measurement setup changes. **Cues:** 1 for a claimed improvement based solely on neatness/trace length; 0 for a measured regression; 2 for quantitative model and paired geometry; 3 for repeated matched measurements. [PDF pp. 1–4, 13–14, Table 1, Figs. 28–29]

**AN139-20 — Plan repeatable EMI precompliance and probing.** **Question/evidence:** Are source, LISN/AN or other applicable artificial network, harness geometry, load, receiver bandwidth/detector, grounding and probe removal documented? Are common and differential modes separable? **Advice/trade-off:** The note recommends conducted checks as an optimization tool and shows an automotive-style, nonsymmetric LISN. That exact LISN and the author's detector simplification do **not** establish compliance for a mains induction cooker; use the eventual applicable standard and lab method. A scope probe can act as an antenna and change an EMI result. **Cues:** 1 for uncontrolled setup or comparison across different fixtures; 0 for confirmed limit failure; 2 for a written valid test plan; 3 for repeatable measurements with margin. [PDF pp. 21–22, Fig. 41]

**AN139-21 — Diagnose unexpected spectral lines before tuning copper.** **Question/evidence:** If peaks fall at fractional or nonharmonic frequencies, do switch-node and gate waveforms reveal skipping, subharmonics, burst operation or control instability? **Advice/trade-off:** An EMI filter cannot cure the source of an erratic commutation pattern. Observe waveform timing with a low-loop probe setup, then remove the probe for comparable EMI scans. For variable-frequency induction control, the note's fixed-frequency equivalence between detectors cannot be assumed. **Cues:** 1 for unexplained sidebands with no time-domain check; 0 for functional instability or failed EMI result; 2 for diagnosis and proposed remedy; 3 for stable waveforms and corrected spectrum. [PDF p. 22, Appendix E]

## Ordered workflow for the later board review

1. **Identity gate.** Re-run the repository baseline check in a checkout that contains it, and verify `CURRENT.tsv`, project, board and full SHA-256 before looking at copper. If anything differs, stop this review and establish the new candidate's identity.
2. **Switch-state diagram.** From the pinned schematic, draw one graph per bridge state and transition. Label capacitor terminals, leg devices/body diodes, snubbers, resonant load, sense elements, return conductors and current direction. Color only *state-difference* branches as fastest-edge loops. Draw a separate map for high-rms tank current and a separate high-dv/dt node map. Attach operating voltage/current/frequency and edge-rate assumptions; retain uncertain states as U.
3. **Physical overlay.** Put those graphs over the routed board with layer names, vias and nearby conductors. Record loop area/inductance estimates, stack spacing, switch-node area, gate-driver loop path and filter/sense reference points. Evaluate thermal/current capacity and insulation alongside EMI geometry.
4. **Rank and test hypotheses.** Prioritize source loop and driver loops, then sense/quiet references, then filter return/coupling. For each change proposal, state predicted effect on overshoot, ringing, temperature, common/differential conducted noise and safety distance. Use a matched operating point; avoid treating AN-139's example values as acceptance thresholds.
5. **Measurement plan.** Capture bridge midpoint, DC-link ripple, each gate-to-its-own-source, driver rails and sense inputs with appropriate bandwidth and low-inductance probing. Compare near-field hot spots and conducted spectra using the applicable fixture. Vary supply, load vessel/coil condition, frequency/control mode and temperature. Record probe configuration because it can alter RF fields. Only assign 3 when the evidence demonstrates margin for the relevant case; use U when it cannot be established.
