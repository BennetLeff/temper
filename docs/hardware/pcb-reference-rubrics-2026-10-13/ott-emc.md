## Common scoring contract

Score each criterion independently for the exact candidate, with a link to evidence. **0 failed**: an observed contradiction or a required path absent; **1 serious concern**: observed geometry, topology, or preliminary data identifies a plausible harmful mechanism with weak mitigation or an unresolved conflict; pure absence of evidence is U; **2 supported design pending verification**: the layout, calculation, or datasheet evidence supports the intent but representative measurement or required approval is absent; **3 verified margin**: relevant tests on representative hardware and cable/enclosure states show margin against a current, explicitly selected requirement, with uncertainty recorded; **U unknown**: needed facts or measurements have not been collected. **NA** needs a written topology-based reason. The anchors below state what would support each score; they assign no present score. A DRC pass cannot alone earn 3 for EMC. No average or total is a manufacturing-readiness verdict.

The rubric's words “Ott” identify book-derived reasoning; “Temper question” is an inference about what the later reviewer should ask of this full-bridge induction cooker. Numeric pass limits must come from the final product classification, markets, relevant standards, and present component data. No criterion is scored at this preparatory stage; all board results remain unassessed.

## Design and routing criteria

**OTT-01 — Draw each fast-current loop, including the return.** Ott: loop area and inductance arise from the complete current path, and the schematic leaves many returns implicit (pp. 120–123, PDF 144–147; pp. 390–392, PDF 414–416). Temper question: for every full-bridge commutation state, gate-drive pulse, DC-link recharge, auxiliary converter edge, and logic transition, where does current actually close? Evidence: annotated layer views, state-by-state current arrows, component parasitics, and scope/current-probe captures. Anchors: 0 = measured failure traced to a return detour; 1 = visible detour with unproven consequence; 2 = short local loops shown in routed copper; 3 = switching waveforms and emissions confirm margin; U = missing maps. Advice/trade-off: place loop-closing elements before optimizing trace lengths; the shortest outbound trace may have a worse return.

**OTT-02 — Partition noisy and susceptible functions before routing.** Ott: close physical coupling, shared impedances, and mixed-signal trace excursions defeat nominal separation (pp. 622–624, PDF 645–647; pp. 660–664, PDF 683–687). Temper question: are bridge power, gate drivers, mains entry, sensors, control, and external interfaces arranged by current and field paths? Evidence: placement map, layer-by-layer partition overlay, receptor sensitivity and source edge-rate list. Anchors: 0 = demonstrated susceptibility/coupling from interpenetration; 1 = source and victim zones visibly interpenetrate without mitigation; 2 = routable zones and controlled crossings; 3 = hot-spot and immunity tests confirm separation; U = no full placement/cable map. Advice/trade-off: prioritize source/victim distance and return geometry; extra distance costs board area and may lengthen necessary control paths.

**OTT-03 — Minimize differential-mode switching-loop area.** Ott: radiated magnetic field tracks loop area and changing current (pp. 464–471, PDF 487–494; pp. 525–526, PDF 548–549). Temper question: are DC-link to switch paths and resonant/load return paths compact in each bridge state? Evidence: scaled copper geometry, loop inductance estimates, measured ringing, H-field scans. Anchors: 0 = failed waveform/emission requirement traced to loop geometry; 1 = broad commutation loop with no performance evidence; 2 = routed loop and parasitic model support the design; 3 = measured field/ringing and emissions have margin; U = no state current map. Advice/trade-off: widening copper for heating may enlarge fields or capacitance; optimize loop shape and thermal capacity together.

**OTT-04 — Keep fast signal references continuous.** Ott: a high-frequency return flows on the nearest reference plane under a trace, regardless of its net name (pp. 391–399, PDF 415–423; pp. 626–627, PDF 649–650). Temper question: can each fast clock, driver command, current-sense edge, and feedback signal retain a nearby continuous return from source to load? Evidence: trace and adjacent-plane overlays plus launch/termination paths. Anchors: 0 = crossing causes demonstrated waveform/EMC failure; 1 = critical crossing lacks a local return; 2 = each critical route has a traced return; 3 = waveform and emission tests confirm; U = trace speed or plane map absent. Advice/trade-off: a nearby power plane can carry return, but any transition to a different reference needs a physical bridge.

**OTT-05 — Treat slots, cutouts, and antipad rows as return obstructions.** Ott: both deliberate slots and overlapping clearance holes can create detours; nonoverlapping holes can preserve paths (pp. 627–629, PDF 650–652, Fig. 16-4 and Table 16-1). Temper question: do isolation barriers, connector clearance, mounting holes, and via arrays sever returns for relevant signals? Evidence: plane polygon inspection at each critical crossing, with current direction. Anchors: 0 = cut causes demonstrated unacceptable behavior; 1 = critical route crosses a cut with an unproven detour; 2 = no crossings or documented local bridge; 3 = measured comparison or full EMC margin; U = plane geometry unavailable. Advice/trade-off: preserve mandated safety isolation; route around it rather than bridging it merely for EMC.

**OTT-06 — Supply a return when changing signal layers.** Ott: the return must change reference planes near the signal via; same-net plane vias are preferable to a distant detour, and a capacitor between unlike power/ground planes has residual inductance (pp. 630–633, PDF 653–656, Figs. 16-7–10). Temper question: for critical transitions, where is the plane-to-plane via or suitable local capacitor, and which surface carries the return? Evidence: route/via inventory with stackup and return annotations. Anchors: 0 = transition causes measured unacceptable behavior; 1 = critical transition has no identified local return; 2 = local topology documented; 3 = A/B waveform or emission margin; U = transition list absent. Advice/trade-off: fewer layer changes simplify routing review; added stitching consumes space and must respect isolation.

**OTT-07 — Choose stackup by field and return goals, not layer count alone.** Ott: signal-to-reference spacing, plane order, power-plane splits, and signal assignment matter; his six goals cannot all be satisfied in every practical stackup (pp. 635–654, PDF 658–677). Temper question: is the fab-controlled stackup documented, and are fast nets assigned to close, solid references? Evidence: fabrication stackup, thickness tolerances, dielectric/copper specs, route-to-plane audit. Anchors: 0 = stackup violates an explicit requirement or causes measured failure; 1 = critical layer has uncertain reference or spacing; 2 = constraints and trade-offs documented; 3 = built stackup verified and emissions margin; U = actual construction unknown. Advice/trade-off: closer signal/plane spacing reduces loop area and crosstalk, but stackup, voltage spacing, heat, cost, and rework can conflict. Do not copy Ott's example mil values automatically.

**OTT-08 — Prefer continuous ground for mixed-signal areas, with disciplined routing.** Ott: a single reference plane plus functional partition often prevents digital return from reaching analog circuits; splitting a plane can force a larger loop (pp. 660–669, PDF 683–692, Figs. 17-1, 17-4, 17-8). Temper question: can sensor and control returns stay local over one continuous safe-side plane? Evidence: net/plane overlay, ADC or mixed-signal IC grounding requirements, actual conversion-noise tests. Anchors: 0 = split crossing violates isolation or causes demonstrated failure; 1 = critical crossing lacks a local return; 2 = routing and IC pin return paths are explicit; 3 = noise/immunity/emission margin; U = partition or IC requirements absent. Advice/trade-off: a split can be justified by true galvanic isolation or an externally imposed requirement, but crossing signals then need an intentional isolation or local bridge. Do not connect across a safety barrier.

**OTT-09 — Keep external connector returns intact.** Ott: a broad plane cutout at a connector forces returns around it, whereas individual clearances preserve paths (p. 634, PDF 657, Fig. 16-11). Temper question: do mains, coil, sensor, and control connectors create large return detours or let noise pass around a boundary? Evidence: connector pinout, all adjacent-layer copper, cable return assignment. Anchors: 0 = connector return causes measured unacceptable behavior; 1 = fast return detours around connector cutout; 2 = local return pins/planes documented; 3 = current-clamp and immunity margin; U = mating cable and plane detail unknown. Advice/trade-off: keep the minimum copper clearances required for safety and connector manufacture; never “fill” an isolation clearance to improve return.

**OTT-10 — Ground copper pours deliberately.** Ott: unconnected or long narrow fills can couple noise and make crosstalk or ESD worse (pp. 634–635, PDF 657–658). Temper question: are pours actually tied to an intended reference with useful short connections, or are there islands near sensing, switching nodes, or I/O? Evidence: zone connectivity report and layer images. Anchors: 0 = floating island causes measured unacceptable coupling; 1 = floating island lies near a critical path; 2 = islands removed or justified with short connections; 3 = emissions comparison supports benefit; U = pour connectivity unknown. Advice/trade-off: fill can improve return continuity or thermal spreading, but adds parasitic capacitance and manufacturing copper balance implications. Switching-node copper needs a separate field/capacitance analysis.

**OTT-11 — Control clock routes and high-edge-rate control signals.** Ott: repetitive, large, fast currents set spectral risk; close clock placement and damping reduce ringing (pp. 623–625, PDF 646–648; pp. 383–384, PDF 407–408). Temper question: which actual signals have the highest edge-rate/current product, including gate controls rather than only the CPU clock? Evidence: measured rise/fall time, source impedance, trace length, overshoot, spectrum. Anchors: 0 = ringing/EMC/timing exceeds a selected limit; 1 = visible break or ringing with unresolved impact; 2 = route and damping/termination justified; 3 = timing plus emission margin; U = waveform unknown. Advice/trade-off: damping can improve EMC but lengthens propagation and may increase switching loss if applied to a power switch gate; size it per signal function.

**OTT-12 — Keep sensitive inputs and feedback loops compact.** Ott: low-level input/feedback circuits are susceptible to RF rectification, and fast fields couple into loop area (pp. 549–551, PDF 572–574; pp. 610–612, PDF 633–635). Temper question: are current, temperature, pan, and interlock sensing loops short, balanced where practical, and away from switch-node fields? Evidence: return maps, sensor source impedance, measured error during worst bridge states, near-field scan. Anchors: 0 = false reading or exceeded noise limit demonstrated; 1 = sensitive input passes near known noisy copper without rejection evidence; 2 = separation/filtering justified by bandwidth; 3 = worst-mode immunity margin; U = sensor limits/cabling absent. Advice/trade-off: filtering improves rejection but can slow fault detection; confirm the protection latency budget.

**OTT-13 — Model decoupling as an installed L-C network.** Ott: the path includes capacitor ESL, pads, traces, vias, and package; above resonance its impedance rises (pp. 431–433, PDF 454–456; pp. 457–459, PDF 480–482). Temper question: for each logic, driver, and isolated-rail load, is the installed loop inductance low enough for its transient current? Evidence: capacitor datasheet impedance, actual mounting geometry, rail-current and allowable droop estimates, measured local rail. Anchors: 0 = measured droop exceeds functional limit; 1 = value-only decoupling claim; 2 = layout plus impedance model support; 3 = rail and EMC margin across conditions; U = transient current or actual MLCC behavior unknown. Advice/trade-off: more capacitance improves low frequency; compact mounting and parallel current paths govern high frequency. A nearby footprint alone is not proof.

**OTT-14 — Examine antiresonance and source interaction.** Ott: unlike capacitors can produce impedance peaks; parallel equal-value paths can reduce high-frequency inductance, but loss and geometry matter (pp. 440–447, PDF 463–470). Temper question: do driver/control rails, DC-link and local bypass networks have an impedance peak at a switching, clock, or ringing harmonic? Evidence: frequency-dependent PDN model, component ESR/ESL and DC bias, impedance or rail-noise sweep. Anchors: 0 = resonance matches an observed instability/noise peak; 1 = large mixed-value bank without analysis; 2 = peak damped or shifted by justified design; 3 = hardware spectrum and stability margin; U = component parasitics absent. Advice/trade-off: blindly adding low-ESR parts can sharpen peaks; deliberate damping dissipates power and occupies space. Ott's example capacitor counts are educational, not a BOM recipe.

**OTT-15 — Put bulk energy where recharge current enters.** Ott: local capacitors supply fast pulses and bulk capacitance replenishes them over longer intervals; power entry is a key placement (pp. 459–460, PDF 482–483). Temper question: where do fast DC-link and auxiliary-rail recharge currents close, and how does the placement affect incoming conductors? Evidence: current-path drawing, voltage ripple and inrush captures, ripple-current/temperature ratings. Anchors: 0 = high ripple/overstress observed; 1 = bulk physically remote from its high-current load; 2 = placement, energy, and thermal calculations support; 3 = temperature and ripple margin on hardware; U = load profiles absent. Advice/trade-off: more bulk energy reduces droop but can increase inrush, enclosure volume, cost, and stored-energy hazards.

## Power entry, cables, enclosure, and transient criteria

**OTT-16 — Separate common-mode from differential-mode conducted noise.** Ott: switch voltage through parasitic capacitance drives common-mode current; commutation current escaping its intended capacitor/rectifier loop drives differential-mode current (pp. 498–501, PDF 521–524; pp. 704–706, PDF 727–729). Temper question: which mode dominates at mains entry and at any external coil/control cable over each operating mode? Evidence: properly terminated LISN traces for both conductors, calibrated mode separator or equivalent phase-aware method, and current probes. Anchors: 0 = measured limit exceedance attributed to a path; 1 = measured spectrum has unresolved mode and a specific risky path; 2 = predicted modes and matching mitigation; 3 = mode-separated test margin; U = no relevant measurement. Advice/trade-off: mode diagnosis prevents oversized filters that consume copper, volume, and leakage budget without attacking the source.

**OTT-17 — Locate the mains filter at the entry boundary and prevent bypass.** Ott: filter performance depends strongly on case bond, entry position, and separation of noisy and clean wiring; proximity coupling can bypass elements (pp. 516–520, PDF 539–543, Figs. 13-22/23). Temper question: do line-side conductors stay physically apart from rectifier/bridge copper and the filter's load side, with a low-impedance chassis path if that architecture applies? Evidence: top/bottom layout, harness routing, enclosure bond, field scan, measured insertion in assembly. Anchors: 0 = bypass produces measured conducted/radiated failure; 1 = visible filter bypass path with unmeasured impact; 2 = segregated routes and bond geometry documented; 3 = assembled emissions margin; U = enclosure/harness unknown. Advice/trade-off: on-board filtering saves parts and space but exposes it to magnetic pickup and longer chassis connections; a separate shielded filter adds cost and volume.

**OTT-18 — Match filter topology to measured mode and terminal impedances.** Ott: source and load impedances determine attenuation; parasitic capacitance across series parts and inductance in shunt paths can defeat a nominal low-pass design (pp. 174–178, PDF 198–202; pp. 511–516, PDF 534–539). Temper question: are the CM choke, DM inductance, X/Y capacitance, and damping chosen from frequency-specific needs rather than nominal labels? Evidence: actual impedance-versus-frequency data, bias/current conditions, LISN and harness setup, insertion-loss sweep. Anchors: 0 = ineffective or unstable filter demonstrated; 1 = installed part curves mismatch the noisy band; 2 = design and parasitic model support band; 3 = measured margin in assembled configuration; U = load/source spectra absent. Advice/trade-off: stronger filtering can raise leakage, size, heat, resonances, or susceptibility to surge.

**OTT-19 — Treat X/Y capacitor roles and safety constraints explicitly.** Ott: line-to-line capacitance addresses DM noise, line-to-chassis capacitance addresses CM noise, and safety-class parts plus leakage budget constrain choices (pp. 511–513, PDF 534–536). Temper question: what is each capacitor's fault role, certified class, voltage/stress rating, placement, and total leakage contribution in the final earthing/isolation scheme? Evidence: exact current datasheets, applicable product standard, leakage calculation and measurement, surge and fault review. Anchors: 0 = wrong safety role or demonstrated excess leakage; 1 = generic capacitance with no certification/budget; 2 = documented qualified selection pending approval test; 3 = current-standard safety and EMC margin; U = product classification unknown. Advice/trade-off: lower impedance CM path can increase touch/leakage current; never copy the book's dated example limits.

**OTT-20 — Characterize chokes and ferrites at actual frequency and current.** Ott: ferrite impedance has resistive and inductive parts that vary with frequency, while choke parasitic capacitance limits high-frequency rejection (pp. 225–227, PDF 249–251; p. 153, PDF 177; pp. 512–513, PDF 535–536). Temper question: are magnetic parts specified for the measured noisy band, normal current, fault/surge stress, heating, and saturation? Evidence: exact part impedance curves at bias and temperature, leakage inductance, winding capacitance, measured insertion. Anchors: 0 = saturation, overheat, or failed required attenuation demonstrated; 1 = part curve conflicts with expected band/current; 2 = frequency/bias model supported; 3 = component and emissions margin tested; U = part or spectrum unknown. Advice/trade-off: extra turns improve lower-band impedance while increasing capacitance and reducing high-band benefit.

**OTT-21 — Inventory parasitic common-mode paths from switch nodes.** Ott: heat sinks, magnetic interwinding capacitance, and primary wiring couple high dv/dt into chassis or secondary circuits (pp. 498–501, PDF 521–524; p. 523, PDF 546). Temper question: where can bridge switch-node displacement current flow through heat spreaders, coil, enclosure, auxiliary converter, sensor wiring, or other intentional and stray capacitances? Evidence: capacitance estimates and measurements, mechanical/electrical assembly map, CM current spectra by operating state. Anchors: 0 = measured coupling causes failure; 1 = known large switch-to-victim capacitance lacks mitigation; 2 = path inventory and safe mitigation documented; 3 = assembled CM margin; U = enclosure/coil/thermal stack unknown. Advice/trade-off: lower stray capacitance may worsen heat transfer, safety spacing, or mechanical design; changing slew rate affects switching loss and must be evaluated holistically.

**OTT-22 — Distinguish protective earth, chassis, circuit return, and isolation.** Ott: safety grounding and RF return are different jobs; chassis/circuit connection location affects cable excitation (pp. 106–111, PDF 130–135; pp. 131–132, PDF 155–156; p. 625, PDF 648). Temper question: which accessible parts require protective bonding, which circuits are isolated, and where are intentional RF paths between circuit and chassis? Evidence: earthing/isolation diagram, fault-current path, bond impedance, present safety standard, enclosure drawing. Anchors: 0 = fault path compromised or unintended barrier crossing; 1 = observed shared bond mixes fault and RF returns; 2 = safety-first architecture with RF returns drawn; 3 = safety verification plus EMC margin; U = enclosure class unknown. Advice/trade-off: a low-inductance RF bond can aid EMC but may conflict with leakage and isolation. Do **not** insert a choke or resistor into mandatory protective earth based on the book's historical example.

**OTT-23 — Make connector and cable paths part of the EMC model.** Ott: an external cable can radiate from tiny common-mode current irrespective of its intended signal; one cable's mitigation can move current to another (pp. 477–484, PDF 500–507; pp. 690–693, PDF 713–716). Temper question: list every mains, coil, sensor, user-interface, service, and communication conductor in its actual installed length and routing. Evidence: cable table, signal/return pairing, shielding, current-clamp sweeps, installation variants. Anchors: 0 = cable emission or immunity failure; 1 = defined external cable lacks a local return or boundary treatment; 2 = cables and returns modeled; 3 = all representative cable variants pass with margin; U = cable definition absent. Advice/trade-off: placing filters on one cable can redirect CM current; rescan all cables after each change.

**OTT-24 — Terminate shields to a meaningful enclosure boundary.** Ott: a 360-degree, low-impedance connection can confine RF shield currents, while a pigtail degrades high-frequency effectiveness; one-end versus both-end termination depends on frequency and ground-potential difference (pp. 84–93, PDF 108–117, Fig. 2-46; pp. 482–484, PDF 505–507). Temper question: for any proposed shielded sensor or control cable, what are the intentional shield current, signal return, enclosure bond, and low-frequency ground-loop paths? Evidence: connector backshell section, bond and cable drawing, clamp comparison. Anchors: 0 = shield current causes measured input/emissions failure; 1 = shield termination visibly leaves an RF detour; 2 = topology justified across bands; 3 = EMI and low-frequency noise margin; U = cable/shield choice absent. Advice/trade-off: both-end RF bonding can increase power-frequency shield current; hybrid termination adds components and must preserve isolation.

**OTT-25 — Give each cable signal a nearby return.** Ott: alternating signal/return or paired conductors shrink cable loops; a lone shared ground in a ribbon cable increases coupling (pp. 94–95, PDF 118–119, Fig. 2-49). Temper question: do any multiway connectors or harnesses carry gate/control/sensor lines without a neighboring return, and is the differential pair truly balanced? Evidence: pinout and mating-harness construction, cable length, common-mode conversion measurement. Anchors: 0 = demonstrated unacceptable cross-coupling or fault; 1 = known fast signal uses one distant shared return; 2 = local pair/return assignment supported; 3 = signal and EMC margin on harness; U = cable assembly unknown. Advice/trade-off: more return conductors raise connector count and cost but usually lower radiation and improve repeatability.

**OTT-26 — Analyze enclosure seams, apertures, and nearby metal.** Ott: a metal enclosure only works as a field boundary if penetrations, seams, and cable transitions preserve that boundary; a plastic enclosure needs a deliberate ESD/RF alternative path (pp. 238–239, PDF 262–263; pp. 267–284, PDF 291–308; pp. 594–604, PDF 617–627). Temper question: what actually encloses the bridge, coil drive, and sensitive electronics, and where are apertures, vents, touch surfaces, and seams? Evidence: current enclosure revision, material/bond details, H-field seam scan, ESD test. Anchors: 0 = known field/ESD entry causing failure; 1 = known open seam or penetration lacks treatment; 2 = boundary and bond design documented; 3 = assembled margin; U = enclosure geometry/version absent. Advice/trade-off: a more closed conductive enclosure can raise cost, heat, service difficulty, and parasitic capacitance. Do not assume a stale enclosure snapshot matches stage15b.

**OTT-27 — Filter susceptible inputs at the appropriate boundary.** Ott: cables can collect both CM and DM RF and nonlinear inputs can rectify it; device-level filters need very short shunt paths (pp. 549–551, PDF 572–574, Fig. 14-2). Temper question: for each external sensor/control input, where is the RF/ESD diversion and what bandwidth or fault latency must remain? Evidence: transfer function, worst-case source impedance, input protection network, RF injection data. Anchors: 0 = false input or damaging transient observed; 1 = unfiltered long lead with no immunity evidence; 2 = filter and timing analysis support function; 3 = immunity plus response-time margin; U = cable and timing limits absent. Advice/trade-off: increasing series impedance or shunt capacitance can corrupt high-impedance measurements or delay a shutdown.

**OTT-28 — Divert ESD current before it reaches sensitive ground.** Ott: an ESD pulse seeks a low-inductance route through chassis/ESD structure, and an external protective-earth wire is too inductive to act as the fast local return (pp. 594–608, PDF 617–631; pp. 608–609, PDF 631–632). Temper question: for accessible controls, connectors, and service points, where does ESD current flow in the actual enclosure, and where could a secondary arc or capacitive upset occur? Evidence: mechanical clearances, TVS return geometry, bond map, contact/air and indirect-discharge tests. Anchors: 0 = damage, unsafe secondary arc, or upset beyond selected criterion; 1 = installed TVS has a long return through sensitive ground; 2 = entry and local diversion path documented; 3 = representative tests with margin; U = touch points/enclosure unknown. Advice/trade-off: tying every transient to logic ground can spread it; added conductive structure affects cost and safety distances.

**OTT-29 — Design surge/EFT protection as an energy and return-path network.** Ott: the shunt protector requires a defined current-limiting source/series impedance, and EFT/ESD differ markedly from high-energy surge (pp. 557–561, PDF 580–584, Fig. 14-10). Temper question: for mains and long external leads, what waveform, source impedance, clamp voltage, energy, follow current, and return path does each device see? Evidence: selected present test standard, source model, exact MOV/TVS/fuse ratings, coordination calculation, fault and bench test. Anchors: 0 = ratings exceeded or protected node fails; 1 = protector path or rating conflicts with expected pulse; 2 = pulse/fault models and selected parts support; 3 = tested immunity/safety margin; U = test class or network impedance unknown. Advice/trade-off: tighter clamps can increase surge current and leakage; larger series elements can hurt normal voltage or dissipation.

**OTT-30 — Suppress relay/contact and inductive-load transients locally where applicable.** Ott: interrupting inductance causes voltage and radiated energy; a local recirculation path shrinks the pulse loop, while RC and diode schemes change release time and contact stress (pp. 308–325, PDF 332–349, Figs. 7-15–18). Temper question: does this exact design include relays, fans, solenoids, or contactors, and which contact or coil is the transient source? Evidence: actual BOM/schematic, load inductance, timing requirement, measured turn-off waveform and field. Anchors: 0 = unacceptable arc, overvoltage, or functional failure observed; 1 = inductive load with a visible uncontrolled interrupt path; 2 = clamp and timing calculation documented; 3 = life and EMC tests with margin; U = load topology unconfirmed; NA = no such load. Advice/trade-off: a simple flyback diode reduces voltage but slows release; an RC network dissipates energy and can stress contacts on closing.

**OTT-31 — Treat harmonic current and flicker as separate mains questions.** Ott: rectifier-plus-bulk-capacitor input current can concentrate near line peaks; flicker relates to transient load current and line impedance (pp. 536–541, PDF 559–564; pp. 723–725, PDF 746–748). Temper question: under heating power steps, startup, and brownout recovery, what mains-current harmonic and voltage-change behavior occurs? Evidence: representative source/load, power analyzer, inrush/current profile, selected market/product requirements. Anchors: 0 = failure against an applicable measured limit; 1 = observed peaky line current with no harmonic assessment; 2 = input topology/inrush and mitigation analyzed; 3 = accredited or correlated compliance margin; U = applicable standard/test unknown. Advice/trade-off: passive reactance adds weight/heat, while active correction adds switching noise, complexity, and failure modes.

## Evidence and test criteria

**OTT-32 — Measure cable common-mode current, then rescan all cables.** Ott: a calibrated clamp around an entire cable reports unbalanced current; cable standing waves and environmental pickup complicate readings (pp. 690–693, PDF 713–716). Temper question: with final harnesses and operating modes, what currents appear on each cable and at which frequencies? Evidence: probe transfer-impedance calibration, cable position sweep, product-off background trace, repeat after each mitigation. Anchors: 0 = measured result exceeds a selected applicable target with corroborating emission; 1 = source-correlated large current or incomplete cable set; 2 = current sweep supports design but compliance untested; 3 = calibrated radiated margin and current correlation; U = no harness measurements. Advice/trade-off: current clamp is fast and diagnostic, not a substitute for formal radiated testing. Ott's printed 5 µA heuristic (p. 693) is historical, not a Temper limit; text extraction incorrectly renders its micro sign as “m.”

**OTT-33 — Use near-field scans for localization, not far-field certification.** Ott: a small H-field probe can compare loop hot spots, but its near-field reading cannot be extrapolated directly to far-field emissions; probe spacing and orientation matter (pp. 694–697, PDF 717–720). Temper question: which bridge loop, filter, cable launch, control trace, or enclosure seam radiates during each switching state? Evidence: fixed-distance scan fixture, probe orientation, frequency trace, before/after comparison. Anchors: 0 = a measured hot spot is tied to an applicable failure; 1 = strong source with uncertain system effect; 2 = sources localized and reduced in repeatable A/B scans; 3 = reduction correlates with formal margin; U = no scans. Advice/trade-off: source reduction can be more robust than shielding, but a quieter local probe reading can move current to another path.

**OTT-34 — Run conducted-emission tests with a valid setup and mode separation.** Ott: LISN port termination, detector type, input protection, and power-line background determine whether a spectrum means what it appears to mean (pp. 700–706, PDF 723–729). Temper question: have line and neutral been measured over the selected standard's band, in all operating states, with current calibration and the correct mode-rejection network where diagnosis is needed? Evidence: LISN calibration, both port traces, analyzer settings, port termination, ambient-off trace, controlled cable layout. Anchors: 0 = measured limit failure; 1 = source-correlated peak remains after setup correction; 2 = valid precompliance traces with provisional headroom; 3 = compliance-grade margin with uncertainty; U = no test. Advice/trade-off: precompliance accelerates iteration; its setup and limits must be reconciled with the current standard before scoring.

**OTT-35 — Verify immunity, functional behavior, and margin together.** Ott: ESD, EFT, surge, conducted RF, and radiated RF challenge different mechanisms; test reproducibility and product operating windows matter (pp. 545–561, PDF 568–584; pp. 717–728, PDF 740–751). Temper question: during maximum heating, power transitions, fault handling, idle, and service interactions, what constitutes safe continued operation, controlled shutdown, or unacceptable upset? Evidence: selected test plan and levels, injection points/polarities, firmware event logs, repeated worst-case tests, temperature and unit variation, safety response timing. Anchors: 0 = observed unsafe or out-of-class response; 1 = preliminary immunity upset has unresolved consequence; 2 = designed immunity paths and preliminary tests; 3 = relevant compliance/safety margin with variability accounted for; U = performance criterion unselected. Advice/trade-off: more filtering or slower edges can improve immunity while degrading response speed, power efficiency, or thermal behavior.

## Conditional decisions for the eventual stage15b application

| Decision | Favor when | Watch for | Evidence that resolves it |
|---|---|---|---|
| Continuous safe-side ground plane plus placement/routing partition | Multiple mixed-signal devices or fast signals need uninterrupted local returns | Digital trace wandering through a sensitive area | Routed layer overlay, return-current map, ADC noise under worst switching; Ott pp. 662–669 |
| Split local plane | A real galvanic or functional isolation boundary demands it, with crossings through proper isolation or one controlled bridge | Trace across a gap, “star” tie far away, overlap capacitance | Isolation/safety requirement, every boundary crossing, field and immunity results; Ott pp. 660–669 |
| RF chassis connection near I/O | Conductive enclosure, suitable safety/isolation architecture, external cables susceptible to CM drive | Leakage, fault-current paths, inadvertent barrier crossing | Earthing diagram, bond impedance, current-clamp A/B, safety review; Ott pp. 131–132, 625 |
| Shielded cable with 360-degree bond | Cable CM radiation or external RF/ESD entry dominates, and enclosure termination is real | Low-frequency ground differential, connector mechanics | Mating connector detail, shield-current scan, sensor-noise test; Ott pp. 84–93, 482–484 |
| On-board filter | Compactness and cost matter; clean/noisy copper can be segregated and Y returns kept short | Switch-node magnetic pickup, filter bypass capacitance, weak chassis path | Installed insertion loss, near-field scan, LISN modes; Ott pp. 516–520 |
| Choke/ferrite, capacitor, or source-layout correction | Chosen after measuring CM/DM mode, frequency, and path | Bias saturation, self-resonance, leakage, current redirection | Spectra plus part curves and A/B changes; Ott pp. 174–178, 511–513 |
| Source damping or slower edge | Ringing is a dominant contributor and timing/thermal budget permits | Switching loss, gate-drive instability, delayed fault action | Device stress, temperature, waveform, EMI A/B; Ott pp. 383–384, 498–501 |
| Extra shielding or conductive enclosure | Source and cable fixes cannot meet a verified requirement | Heat removal, cost, service, seams and penetrations, parasitic capacitance | Full assembly scan and immunity test; Ott Ch. 6 and pp. 594–604 |

The matrix is a decision aid, not a recommendation to add a particular component. Ott's examples often use digital-computer or generic switched-supply topologies. Applying them to a full-bridge induction heater requires the actual switching frequency and edge spectra, DC-link/ringing behavior, tank and coil geometry, final enclosure, protective-earthing classification, insulation barriers, harnesses, and exact component ratings. The apparent shortest RF return may cross a required safety boundary; in that case the safety boundary wins and the EMC architecture must change.

## Priority order and inputs to collect

First, preserve candidate identity and collect a coherent as-built package: pinned schematic and routed copper, exact stackup, enclosure and cable revisions, power/ground/bond map, and installed component list. Define applicable standards and functional immunity criteria with the compliance and safety owners. This is the point at which U criteria can become testable, without pretending that the book supplies compliance limits.

Second, identify sources and returns by operating state: full-bridge commutation, coil current, gate pulses, rectifier recharge, auxiliary supplies, clocks, and sensor paths. Review OTT-01 through OTT-15 against layer overlays and current paths. Use state-specific power and fault cases; the most severe EMC state may differ from the maximum average-power state. Keep the isolation barrier and safety spacing explicit in every drawing.

Third, collect bench spectra and time-domain evidence. With suitable safe test facilities, measure bridge/driver waveforms, rail noise, LISN line/neutral conducted spectra, mode separation, CM current on all representative cables, H-field hot spots, and enclosure seams. Track exact test configuration and background. An apparent clean result at one cable location or one heating state is insufficient because standing waves, cable coupling, and operating windows can move the peak.

Fourth, change the dominant measured path, then repeat the full cable/filter scan. Compare source-layout correction, bond/filter topology, damping, and shielding by measured benefit against switching loss, temperature, leakage, surge stress, cost, assembly and service burden. Only then set score 3 against current selected limits with measurement uncertainty and production variation.

Unresolved inputs: applicable market and product EMC/safety standards; intended earthing and touchable-metal scheme; final enclosure and coil/harness geometry; assembly stackup and fabrication tolerances; exact stage15b BOM and data sheets; waveform edge/current distributions; sensor bandwidth and safety shutdown latency; laboratory setup and representative operating profiles. These determine whether several criteria are applicable and what “margin” means. Until they are available, the proper current state for this resource-derived rubric is **unassessed**, not a numeric board grade.

## Source-use notes

The source is useful for causal questions: where current returns, why a filter can be bypassed, why a shield needs a termination, and which bench measurement localizes which mechanism. It is much weaker as a direct 2026 design table. Several PDF text-extraction errors flip units or symbols: rendered printed p. 693 says 5 microamperes, while the extracted text says 5 milliamperes; other extracted μ, ±, and superscripts are likewise unreliable. The rendered figures and cited page images were used to verify spatial claims. Current datasheets, standards, safe test procedures, and physical verification must decide actual values and verdicts.
